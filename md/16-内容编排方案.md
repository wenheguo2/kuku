# 16 - 内容编排方案

> **定位**: 定义现有内容（故事/歌曲/教学，数量详见 [08 §0.1](08-本地开发实施步骤.md)）如何与"陪伴养成系统"编排联动，让**养成成为内容消费的正反馈**，而非独立玩法。
> **权威源**: 养成规则以 [13-陪伴养成系统设计](13-陪伴养成系统设计.md) 为准；本文只解决"内容 ↔ 养成"的映射与运营编排。
> **总原则**: 内容为主、养成为辅（护栏 G5）。进度唯一来源为消费内容 + 挑战（护栏 G1）。

---

## 1. 内容资产与养成的映射关系

```
故事/歌曲/教学内容
      │ 首次完整消费
      ▼
   字/词（知识点）──── 四级朋友养成（未遇见→已相识→好朋友→好伙伴）
      │ 里程碑达成
      ▼
   朋友收集册（按学科可视化）── 里程碑达成 ──▶ 成就贴纸（纯收藏）
```

| 层级 | 资产 | 养成触点 |
|:--|:--|:--|
| L0 内容 | **教学段（识字/英语/拼音）** + 天然绑定单字/单词的识字故事、英语故事 | 首次完整收听 → 关联字词标记「已相识」 |
| L0′ 纯消费内容 | 普通故事/歌曲（无明确单字/单词绑定） | 仅作内容消费，**不驱动字词养成、不做字词关联** |
| L1 知识点 | 字/词 | 四级朋友晋级的最小单位 |
| L2 收集册 | 汉字/单词朋友册 | 按学科汇总各字/词朋友等级 |
| L3 成就贴纸 | 里程碑纪念贴纸 | 达成节点（如集齐某学科好伙伴）发放 |

> **字词关联范围（决策 R7）**：只有**教学内容**天然与字词绑定——识字故事针对某个字、英语故事针对某个单词，对应关系明确；拼音/识字/英语教学段本身即以字词为单位。**普通故事/歌曲不做字词关联、不需要额外抽取字词索引**，仅作为内容消费。因此养成晋级的字词触点只来自 L0（教学 + 字词绑定故事），不来自 L0′。

## 2. 里程碑触发编排（对齐 13 号 §3）

| 行为 | → 朋友等级 | 编排要点 |
|:--|:--|:--|
| 首次完整听关联内容 | 已相识 | 以内容播放完成事件触发，非重复计 |
| 听过后普通挑战通过 | 好朋友 | 挑战入口在内容后自然出现 |
| 直接普通挑战通过 | 好朋友 | 跳过收听也可，直接标记 |
| 综合挑战通过 | 好伙伴 | 自动 10 字触发或主动选字 |
| 直接综合挑战通过 | 好伙伴 | 直接标记 |

> 朋友等级由三个里程碑（听 / 普通挑战 / 综合挑战）逐级点亮，层级覆盖；不设任何虚拟货币/积分。

---

## 3. 成就贴纸 ↔ 内容主题呼应

> 让成就贴纸与内容学科/主题呼应，强化"消费内容→养成"的叙事。贴纸为纯收藏纪念，无兑换、无货币属性。

| 贴纸主题 | 呼应内容 | 触发节点（示例） |
|:--|:--|:--|
| 品格小卫士 | 生活/品格养成故事、儿歌 | 该学科交到 N 个好朋友 |
| 自然探索家 | 自然/科普/动物故事 | 该学科交到 N 个好朋友 |
| 传统文化通 | 神话/传统文化/诗词蒙学 | 该学科交到 N 个好伙伴 |
| 长篇冒险家 | 大 IP / 长篇章回作品 | 完整听完某章回作品 |

- 贴纸发放为**软激励**：达成里程碑时提示"获得一张纪念贴纸"，不强制、不影响功能。
- 贴纸只做收藏展示，不可交易、不可兑换、不设专用货币（护栏 G1/G2）。

---

## 4. 朋友收集册的编排

- 朋友收集册按学科（识字 / 拼音 / 英语…）罗列所有字/词及其四级朋友等级（颜色标识）。
- 支持按亲密度级别筛选（全部 / 未遇见 / 已相识 / 好朋友 / 好伙伴）；★ 只升不降·无间隔复习（无“想念中”）。
- 定位为中性收集统计（护栏 G4），非成绩单/排名。
- 收集册 UI 由前端组件实现（四级色 + 卡片），无额外重美术。

---

## 5. 内容编排的运营节奏

| 周期 | 编排动作 |
|:--|:--|
| 上线首发 | 每学科先出 1-2 款成就贴纸，跑通"内容→朋友→贴纸"闭环 |
| 月度 | 结合内容更新主题，追加成就贴纸，保持新鲜感 |
| 节日/大 IP | 限定主题成就贴纸（仍免费、纯收藏），拉动内容消费 |
| 数据回看 | 监控各学科好朋友/好伙伴增长，指导内容与挑战编排 |

---

## 6. 数据与字段联动（面向开发）

- 内容播放完成事件 → 后端更新 `learning_progress`（`current_stage` 升级，见 [02-技术架构设计](02-技术架构设计.md)）。
- 成就贴纸状态挂在 `child_achievements` 表下（`achievement_type=sticker`）。
- 展示层一律用养成话术映射（`design-tokens.json` 的 `friendLevels`），技术字段名保留。
- API 复用 `/api/v1/achievements/{child_id}` 与 `/api/v1/achievements/{child_id}/collection`（见 [11-API接口文档](11-API接口文档.md)）。

---

## 7. 红线自查（编排环节）

- [ ] 进度不引入内容消费以外的推进途径（护栏 G1）
- [ ] 成就贴纸为纯收藏，不设专用货币、不氪金、不可交易（护栏 G2）
- [ ] 无打卡/连续天数/积分兑换/经营模拟（护栏 G4）
- [ ] 养成入口不喧宾夺主，内容始终是首屏主体（护栏 G5）
- [ ] 睡眠定时（睡眠功能）生效，无压力型设计（护栏 G6）

---

## 8. 依赖

- 成就贴纸美术产能：即梦生成 + IP-Adapter 角色一致性（能力已具备）。
- 内容-字词关联索引：**仅教学段与字词绑定的识字/英语故事**依赖现有 timeline/字词索引（决策 R7）；普通故事/歌曲无需抽取字词索引。编排前核对教学侧覆盖度即可。
- 上线前编排结果并入 [14-AI用户体验测试方案](14-AI用户体验测试方案.md) 走查与 [15-上线合规与资质checklist](15-上线合规与资质checklist.md) 门控。
