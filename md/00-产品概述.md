# 酷酷儿童故事 — 产品概述

> **版本**: v1.2  
> **日期**: 2026-07-15  
> **状态**: 专家审核后修订（决策清单已同步更新）  

---

## 1. 产品定位

**酷酷儿童故事** 是一款面向 3-12 岁儿童及其家长的「听故事 + 唱歌曲 + 学知识」一体化内容产品。

产品以 **音频内容为核心**，结合 **角色立绘** 和 **场景插画**，为儿童提供沉浸式的故事聆听、歌曲跟唱和互动学习体验。

### 一句话描述
> 孩子听着酷酷的故事长大，唱着好玩的歌曲变聪明，在互动中学会识字、英语和拼音。

## 3. 目标用户

### 3.1 核心用户：3-12岁儿童

| 年龄段 | 分级标识 | 需求特征 |
|:--|:--|:--|
| 3-5岁 (幼儿) | L1-L2 | 短故事、摇篮曲、简单认知 |
| 5-7岁 (学前) | L3-L4 | 品格故事、儿歌、识字启蒙 |
| 7-9岁 (低年级) | L4-L5 | 历史/科学故事、英语启蒙、拼音 |
| 9-12岁 (高年级) | L5-L6 | 长篇章回、深度故事、英语学习 |

### 3.2 决策用户：家长

- 查看孩子的成长进度（本周/月/年结识多少字词朋友，未遇见/已相识/好朋友/好伙伴各多少个）
- 支持多个孩子档案分别记录
- 信赖优质内容，关注教育价值
- 重视安全性（无广告、无不良内容）

- 生活认知 (9分类): 口才、财商、社交、安全教育...
- 自然科学 (7分类): 动物、植物、天文、物理化学...
- 神州之外 (9分类): 西方童话、神话传说、科幻幻想...
- 双界之门 (11分类): 互动叙事、故事修复师...
- 上下五千年 (8分类): 历史故事、神话故事、成语故事...
- 蒙学启蒙 (10分类): 三字经、百家姓、诗词...

### 4.3 成长教学 (Education)

| 维度 | 数据 |
|:--|:--|
| 课程总数 | 详见 08 §0.1（教学课程实测数） |
| 识字 | 3,499 个常用字 (含习题) |
| 英语 | 3,910 个单词 (含习题) |
| 拼音课程 | 100课 |
| 交互形式 | 横屏三面板：左插图区(场景+透明底立绘) + 下字幕区(高亮学习字词) + 右字词信息区(大字+拼音+释义+组词+例句+笔画) |
| 文件结构 | 每课含学习1/学习2/学习3（三个独立复习角度）。每学科前10%课程免费体验，其余课程需会员解锁 + 习题(16题: 4听音选字+4看字选拼音+8看字选组词) |

> **四级朋友养成系统（层级覆盖，话术唯一权威源见 [13-陪伴养成系统设计](13-陪伴养成系统设计.md)）**：⚪未遇见(0) → 🟡已相识(1) → 🔵好朋友(2) → 🟢好伙伴(3)
> - 学习1/2/3三个独立复习角度，互相独立无先后顺序；付费边界在课程数量（前10%免费）
> - 可直接进入挑战跳过收听，通过即成为好朋友(2)
> - **普通挑战通过标准（按学科区分）**：识字(1X听音选字对+3-9X看字选词≥1道对, 2X可错)；英语(1X+2X对+3-9X≥1道对)；拼音无习题
> - **综合挑战逐字判定（比普通挑战更严格）**：识字(1X+3-9X全对)；英语(全对)；8/10字通过
> - ★ 朋友等级只升不降：任何挑战未通过都不降级；综合挑战答错的字保持原级、答对才晋升好伙伴
> - ★ 无惩罚·可无限重试：普通挑战未过始终可“再试一次”；已下线间隔复习/久别重逢机制
> - 陪伴养成正反馈：角色鼓励语+成就贴纸+朋友册可视化（纯展示型，不做打卡/连续天数）
> - 重试机制：★ 普通挑战无惩罚、可无限重试，直到通过为止

**教学 segments 特有字段**:
- `characters[]`: 每段包含角色名、姿势(pose)、表情(emotion)
- `location`: 场景位置 (厨房/教室/花园等)
- `synopsis`: 课程概要
