## 二、本次修复（R2 唯一真缺口）

**问题**：监护人同意撤回是儿童合规闭环（《个人信息保护法》要求可撤回），后端 `POST /user/consent/withdraw` 早已实现（撤回留痕 `withdrawn_at`、重登需重新同意），但前端 20+ 处 api 调用中没有任何页面调它——用户在协议页看到"监护人可以拒绝或撤回同意"却无处可点。

**修复**（`miniapp/src/pages/common/agreement/index.tsx`）：
- 儿童个人信息保护规则页（`type=children`）**登录态**显示「撤回监护人同意」按钮；
- 点击 → `showModal` 二次确认（说明后果：退出登录、成长功能暂停、重登需重新同意）→ `POST /user/consent/withdraw` → `logout()` 清全部本地会话 → 回首页；
- 失败 toast 提示，`submitting` 防重复提交。

**文档同步**：`开发文档/miniapp/README.md`（agreement 行 + 变更记录）；md/11 §2.6 已有该接口定义，无需改。
