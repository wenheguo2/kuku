## 二、家长组反馈详录

### P1 林女士（3岁娃妈妈，谨慎焦虑型）

**满意**：
- "无广告、无不良内容"的定位正中下怀；13 号养成系统去掉打卡/连续天数、无惩罚设计，让我不担心孩子被套路。
- 故事播放器有定时关闭（ST-048），哄睡场景可用；摇篮曲、冥想放松分类齐全。

**问题/意见**：
1. **哄睡模式还不够"一键"**：定时藏在播放器里，希望首页或播放器有明显的"睡前模式"入口——一键切暗色 + 自动定时 + 音量渐弱。文档里有夜间/睡前模式设计，但要确认 MVP 是否真做进去。
2. **3岁孩子不识字**，S-01 首页信息密度（搜索+banner+继续收听+大IP+推荐+热点+学科网格）对幼儿太复杂。建议按孩子档案年龄（L1-L2）自动收敛首页，幼儿档案下首页只留"大图卡片 + 继续听"。
3. 担心孩子自己乱点进付费页。**希望有"儿童锁"**：进入会员购买/支付页（A-03/A-04）前加家长验证（如计算题/长按），这也是同类产品标配与合规惯例。
4. 音频音量：不同 TTS 批次响度是否一致？孩子睡着后突然一首响度高的歌会吓醒。建议管道统一响度（loudnorm）并作为验收项。

**方向建议**：把"哄睡"做成独立心智（睡前专区 = 摇篮曲 + 冥想 + 轻故事 + 自动定时），这是 3-5 岁家长的第一付费理由。

### P2 王先生（IT 爸爸，隐私敏感型）

**满意**：
- 有 A-05 账号注销/数据删除页规划（`DELETE /api/v1/user` 全量删除），15/17 号合规文档比多数小团队认真。
- 题目判分在服务端、答案不下发，说明团队有安全意识。

**问题/意见**：
1. **儿童个人信息保护**：产品面向 3-12 岁，属《儿童个人信息网络保护规定》适用范围。孩子档案（昵称/年龄/性别）收集前是否有**监护人同意的显式勾选**？隐私政策里要有儿童条款专节。19 号"个性化点名故事"要收集孩子名字甚至**父母声音克隆**——这是敏感项，必须单独授权、可单独删除，声音样本存储与销毁策略要写清楚。
2. 微信授权登录（A-01）：希望支持"游客先试用、再登录"，别一上来就要授权。文档未明确是否强制登录。
3. **注销后 CDN 上的播放记录类数据**是否也清？收藏/进度在服务端删了，本地 Taro Storage 缓存也要同步清空。
4. 建议提供家长中心的"数据导出"（孩子学习记录），既是卖点也是合规加分项。

**方向建议**：把"隐私安全"做成显性卖点（如设置页里的"儿童保护说明"页），对我这类家长的转化率影响很大。

### P3 张女士（鸡娃型妈妈）

**满意**：
- 识字 3,499 字 + 英语 3,910 词 + 拼音 100 课，量级足够小学前后全程使用；每课 16 题的习题结构清晰。
- C-02 学习进度有周/月/年 + 阶段统计 + 每日柱状图，是我最想看的。

**问题/意见**：
1. **"只升不降 + 无限重试"我理解初衷，但我想知道真实掌握度**。好朋友/好伙伴等级看不出"这个字孩子到底会不会"。建议家长端（仅家长可见）保留一个客观维度：如"最近一次挑战正确率"或"易错字清单"，孩子端保持温柔叙事不变，两端分离。
2. 课程只能按编号顺序列出？希望有**"按孩子已认字自动推荐下一课"**，否则我要自己翻 3,499 个字找起点。建议至少做个"入学摸底"（可选、家长发起），定位孩子起始水平。
3. 学习1/2/3 三个角度互相独立，家长不清楚"学完"的定义。课程详情页应说明三个角度分别练什么（音/形/义），否则家长会以为是重复内容。
4. **周报推送**：希望每周一条微信服务通知："本周结识 12 位字词朋友，8 位成为好朋友"。纯展示型、不施压，符合 13 号护栏。

**方向建议**：家长端做"效果可感知"，孩子端做"过程无压力"，两条线别互相污染。

### P4 陈先生（加班爸爸）

**满意**：
- 迷你播放栏（GL-02）跨页常驻，切页面不断播，通勤给孩子放故事很顺。
- 多孩子档案在规划中（P1 阶段）。

**问题/意见**：
1. **"继续收听"必须极其可靠**。章回作品（三国 100+ 回）听到第 37 回，换个设备/隔三天回来必须一秒续上。跨设备进度同步是否 MVP 内？文档里进度云同步的口径要明确。
2. 我经常是"人不在场"的家长：希望家长中心有**"今天听了什么"时间线**（C-04 播放历史已有雏形，建议加每条时长），我加班回家扫一眼就知道孩子今天听了 40 分钟三国。
3. 会员家庭共享：我买年卡，孩子用妈妈手机也在听——**同一账号多设备策略**要定义（同时在线数？踢下线？），别让正常家庭使用被当成账号共享封掉。
4. 离线下载排在 P1（APP），但小程序场景下高铁/飞机/地库都没网。哪怕 MVP 做不了下载，也建议做**激进的分段预取缓存**（正在听的章回预取后 2-3 章）。

### P5 刘奶奶（63岁，隔代带娃）

**问题/意见**（老人视角，全部是可用性问题）：
1. **字太小看不清**。设计稿是给年轻人看的，我需要"长辈模式"或全局大字号开关（C-06 设置页应加字号档位）。
2. 图标看不懂，**Tab 和按钮要有文字**。"故事/歌曲/成长/家长"四个 Tab 有字就好，播放器里的循环/定时等图标也希望有文字标签。
3. **最怕误触付费**。我不会用微信支付，孩子点进支付页我会慌。再次强调家长验证锁的必要性（与 P1 一致）。
4. 我想要的核心操作只有三个：找到孩子常听的、按播放、调音量。建议首页"继续收听"卡片做得**大而醒目**，我一按就行。
5. 语音搜索：我打字慢，孩子说"要听孙悟空"，我希望按住说话就能搜（微信小程序有语音接口，可 P2 排期）。

**方向建议**：隔代带娃是音频类产品的高频真实场景，"老人可独立操作"应作为一条验收标准（14 号 AI 用户测试建议加一个"老人画像"）。

### P6 赵女士（价格敏感，二胎）

**满意**：
- 月卡 ¥9.9 早鸟价低于同类（凯叔/喜马儿童普遍 20+），年卡 ¥88 有竞争力。

**问题/意见**：
1. **免费边界至今"待确认（O-1）"是最大风险**。作为价格敏感用户，我下载后 10 分钟内的免费体验决定去留。建议尽快定：每个学科前 N 个故事免费 + 每天 1-2 个限免，比"固定基础免费"更能拉活跃。
2. **二胎家庭**：3岁和8岁孩子需求完全不同，多孩子档案（A-02）在 P1，但会员权益是否覆盖同账号下所有孩子档案？必须明确"一份会员全家孩子可用"，这是我买年卡的前提。
3. 免费用户朋友等级最高到"好朋友"，综合挑战是会员专属——**孩子努力到一半被付费墙拦住会哭**。建议门槛前移：进入课程时就区分免费/会员，而不是让孩子练完了发现"晋级要会员"。孩子的挫败感会转化为家长的反感。
4. 建议有**分享得体验会员**（如分享给好友得 3 天）：小程序生态标配，拉新成本低。但注意别做成诱导分享（微信平台红线），用"家长主动分享报告"形式更安全。

### P7 周先生（佛系放养型）

**满意**：
- 没有排行榜、没有连续打卡、没有 PK，13 号的克制设计非常对我胃口，市面上少见。

**问题/意见**：
1. 就一条核心诉求：**每日时长上限**。设置页（C-06）目前有主题/定时/复习间隔，建议加"每日收听提醒"（如满 60 分钟温柔提示休息，可由家长设定，默认关闭）。注意用鼓励休息的话术，别做成强制锁死（否则孩子哭闹反而怪产品）。
2. 教学播放器是横屏视觉型（PL-03），我更希望孩子**多听少看**。建议故事/歌曲场景默认息屏可听（小程序后台播放能力要确认），且在家长中心能看到"纯听时长 vs 看屏时长"的比例。
3. 内容推荐别做成算法投喂。S-01 的"换一换"推荐是运营池（10 §3.7 home_index），这个思路好，请保持人工/规则编排，别学短视频。

### P8 吴女士（护眼焦虑，孩子已近视）

**问题/意见**：
1. **教学播放器横屏三面板是产品里唯一强看屏的模块**，对我是双刃剑。建议：① 每课时长控制在 5-8 分钟并在课程详情标注时长；② 连续学习 2 课后插入"休息一下"过场；③ 右面板大字+笔画是视觉核心，插图区可提供"简洁模式"减少视觉刺激。
2. 深色/夜间模式（PR-004a，深/浅/跟随系统）必须 MVP 落地，且**播放器页面优先适配**——睡前场景刺眼白底是差评重灾区。C-06 设置页目前无设计稿（❌），需尽快补。
3. 字体：儿童阅读建议无衬线圆体、字号下限管理。design-tokens 里应固化"儿童可读性最小字号"，别让开发随手写 10px。
4. 横屏教学是否支持**投屏/投电视**？大屏对视力更友好，可作 P2 方向（小程序限制多，APP 阶段做）。

### P9 郑先生（传统文化爱好者）

**满意**：
- 蒙学启蒙 10 分类、上下五千年 8 分类、诗词歌曲 252+ 个目录，内容广度是真材实料；章回作品（三国）总入口 + 连续播放（S-04）符合听书习惯。

**问题/意见**：
1. **内容准确性是这个品类的生命线**。AI 生成 + 双重机审 + 抽审（R6）对故事类够用，但**史实类/诗词类建议提高抽审比例**：诗词原文、作者朝代、历史事件年代错一个字就会被家长截图传播。建议：蒙学/诗词/历史三类做专项校对清单（原文类内容与权威版本逐字比对可以脚本化）。
2. 多音字、破音字在 TTS 里错读是高发问题（"骑"jì、"斜"xiá 等诗词旧读也有争议）。建议建立**读音勘误反馈入口**：播放器内长按/点按"报错"，家长顺手报，后台聚合修复。这比内部抽审更能兜底。
3. 三国等大 IP 改编要注意年龄适配的分寸：11 岁孩子会拿原著对照，改编过度会被吐槽"魔改"。建议章回作品页标注"改编说明"（基于 XX 版本，面向 X 岁+）。
4. 希望诗词类课程与诗词歌曲**互相跳转**（学了《静夜思》→ 一键去听《静夜思》歌）。16 号内容编排提到映射，落地时请把这条链路做通，这是差异化亮点。

### P10 孙女士（英语启蒙执念）

**满意**：
- 3,910 个英语单词 + 双语/英文歌曲，覆盖面够；歌词 LRC 逐行高亮对磨耳朵很有用。

**问题/意见**：
1. **英语发音质量是硬门槛**：TTS 英语音色是否地道？建议英语课程与英文歌用**独立的英语原生音色**，中式口音会被英语启蒙家长一票否决。上线前请拉 20 个英语课样本做家长盲测。
2. 英语课挑战全对才通过（比识字严），但 5 岁孩子拼写/辨音能力有限，**低龄档案建议自动放宽或隐藏综合挑战**，按 L 级分层难度。
3. 缺"跟读"是明确的（PL-03 无跟读/倍速），理解 MVP 取舍，但请在路线图上给跟读评分排 P2 优先位——英语启蒙用户最终都会问这个功能。
4. 英文歌的 LRC 建议支持**中英对照双行显示**（原文 + 译文），幼儿家长需要给孩子解释歌词。

## 三、儿童组反馈详录

> 儿童反馈由模拟画像推演，以"孩子会说的话 + 背后的产品含义"呈现。

### K1 糖糖（3岁，黏人、注意力短）

- "还要听小兔子那个！"——**低龄核心行为是无限重复同一内容**。播放器需要"单曲循环"一键可达（3 岁场景由家长操作，但要好找）。
- 听到一半睡着 → 定时关闭必须有"播完本曲/15/30分钟"档位。
- 含义：幼儿档案的播放器应默认简化：大按钮、循环、定时，隐藏进度条拖拽等复杂控件。

### K2 石头（4岁，好动、乱点屏幕）

- 乱点屏幕会点出什么？**误触是 4 岁常态**：点到返回退出播放器、点到搜索、点到会员页。
- 含义：① 播放中误触保护（如"小手锁"：长按解锁才能操作，家长可开启）；② 全部弹窗按钮要大且间距足，禁止"确认/取消"紧贴；③ 会员页面对儿童档案要有家长验证（再次呼应 P1/P5）。
- "我要听挖掘机！"——搜索必须容错：拼音输入、错别字（"挖屈机"）、同义词（"翻斗车/卡车"）。C-05 搜索的联想设计要面向"家长代打字 + 孩子口述"场景。

### K3 朵朵（5岁，害羞、爱重复）

- 跟着儿歌小声哼，但不敢大声唱。**歌曲播放器的歌词高亮 + 角色立绘一起"唱"的氛围**对她是鼓励——建议 PL-02 在歌词高亮之外加一个角色跟着节奏动效（低成本 CSS 动画即可）。
- 反复听《小星星》27 遍 → "最近常听"应按她的真实行为浮上来，比算法推荐重要。
- 挑战答错时她会脸红想躲。13 号"无惩罚 + 角色鼓励语"的设计对害羞儿童非常关键，**答错音效必须温柔**（不要"叮咚"错误音，建议角色轻声说"再想想～"）。这条应写进验收：错误反馈不使用负面音效/红色大叉。

### K4 天天（6岁，十万个为什么）

- 十万个为什么 640 个分类目录是宝藏，但他会连环追问："为什么天是蓝的？那晚上为什么是黑的？"——建议故事播完后的"猜你想问"**推荐同主题相邻条目**（同分类内相关推荐），把连环好奇心接住，提升连听时长。
- "这个我听过了！"——**已听标识**很重要：列表页对听完的条目打上小对勾/耳朵图标，孩子自己会找没听过的。
- 含义：S-03 列表页需要"已听/未听"状态位，数据来自播放进度记录。

### K5 米妮（7岁，好胜心强）

- 是养成系统的核心受众："我要集齐贴纸！我要都变成好伙伴！"
- **免费墙的挫败感在她身上最明显**（与 P6 呼应）：她冲到综合挑战入口发现要会员，会直接哭给家长看。这对转化可能是好事，但对口碑是坏事——建议综合挑战入口对免费用户显示为"和爸爸妈妈商量后开启"的温柔话术，而不是硬付费弹窗。
- 好胜心强的孩子会想看"我比别人厉害"。产品刻意不做排行榜（合规正确），但可以给她**"自己和自己比"**：朋友册里"上个月的我 → 这个月的我"对比视图，满足好胜心又不引入社交攀比。
- 贴纸目前是纯展示型。建议贴纸有**获得瞬间的仪式感**（全屏彩带动效 3 秒），这是她坚持学习的最大燃料，成本极低。

### K6 虎子（8岁，恐龙/动物迷）

- 打开 App 只想找恐龙。**兴趣直达**是他的核心诉求：① 搜索"恐龙"必须能同时召回动物世界的故事、相关歌曲、相关课程（跨 Tab 搜索结果分组展示，注意与"搜索 Tab 隔离原则"协调——建议默认全局分组、Tab 内搜索保持隔离）；② 首页"猜你喜欢"应基于他的收听品类倾斜。
- "有没有新的恐龙故事？"——**上新提醒**：对他收藏/常听的分类，有新内容时在分类卡片上打"新"角标。内容还在持续生成中（18万段+），上新是天然的留存钩子，目前文档里没看到上新机制的产品化设计，建议补。
- 他会给同学"安利"：孩子间口口相传是真实增长渠道，"分享一个故事给同学"链路（微信卡片分享出去，对方点开直达播放页）要顺滑，且分享出去的内容如果是会员内容，允许**限时免费听一次**——这是最强的裂变素材。

### K7 小雨（9岁，安静爱幻想）

- 双界之门"互动叙事、故事修复师"11 个分类是她的天堂，但目前播放方式是"整曲 MP3 纯听"——**互动叙事不互动**，名不符实的落差要管理：要么在故事内做简单分支选择（P2/P3 方向，改造成本高），要么在文案上别过度承诺"互动"。
- 她听完好故事会想"接着幻想"：建议故事播放页有**"我给故事画个结尾"**类轻延伸（P2，哪怕只是收藏+涂鸦入口），把深度用户的情感留住。
- 9 岁女孩对角色 IP 的情感投入最深：13 个角色立绘资产雄厚，但目前角色主要出现在教学播放器里。建议**角色在故事 Tab 也有存在感**（如每个学科由不同角色"代言"当向导），把 IP 资产用起来——这正是对喜马拉雅/凯叔的差异化点（00 §8 里自己也这么写了，落地要跟上）。

### K8 阿哲（10岁，三国迷、话痨）

- S-04 章回连播 + 从第 1 章连续播放，命中他的核心场景。补充诉求：
  1. **倍速播放**：10 岁+听书用户普遍要 1.25x/1.5x（PL-03 明确无倍速，但 PL-01 故事播放器建议 MVP 就支持，技术成本低）。
  2. **跳转指定回目**要方便：100+ 回的目录需要支持快速滑动定位/回目搜索。
  3. "昨天听到哪儿了"：断点续播精度到秒，且章回作品在首页"继续收听"要显示"第 37 回 · 还剩 8 分钟"。
- 他会挑刺："这个和我看的三国不一样！"（与 P9 的改编说明建议呼应）。
- 大 IP 故事是会员内容——10 岁孩子已有零花钱意识但无支付能力，他会持续给家长施压，这是设计好的转化路径；但**试听钩子要给足**：章回作品建议前 3-5 回免费，听进去了家长才愿意买。

### K9 悦悦（11岁，学霸、自尊心强）

- 英语课对她偏简单的部分会跳——**"可直接进入挑战跳过收听"**（00 §4.3）设计正确，保留。
- 自尊心强的孩子最怕"被当小孩"：11-12 岁使用 3-5 岁同款界面会尴尬。建议 UI 按档案年龄微调**视觉成熟度**（L5-L6 档案：更沉稳的配色/更少的"幼态"贴纸风），设计系统里的颜色令牌应预留年龄分层主题。这是 9-12 岁留存的关键，也是同类产品普遍做不好的点。
- 她要"学习的掌控感"：希望能看到自己的学习地图（3,499 字里我认识多少、分布在哪些课）——朋友收集册（growth/collection 已有页面）本质就是这个，建议对高年龄档案提供**统计视图切换**（收集册故事化视图 ↔ 数据总览视图）。
- 诗词歌曲对她是"背诵神器"：建议诗词类歌曲播放页可切换"看原文全文"模式（LRC 高亮之外整首诗静态展示），方便跟背。

### K10 大壮（12岁，有点厌学，抗拒幼稚）

- 最难伺候的边缘用户，代表产品年龄上限的真实拉扯：
  1. "这是给小屁孩用的吧"——**品牌观感**在 12 岁是流失主因。放声大笑（220+ 目录）、青春之歌是留住他的钩子，但入口若埋在"幼态"首页里他根本不会翻到。建议 L6 档案首页优先展示这些"大孩内容"。
  2. 他不会做题，但会听搞笑故事和历史八卦——**"纯听不学"路径必须无摩擦**：任何时候都不要向他弹"来挑战一下吧"。13 号护栏"不做打卡施压"要扩展为"对高年龄档案不做学习引导打扰"。
  3. 实话实说：12 岁的注意力竞争对手是短视频。产品对 10-12 岁的合理定位是**睡前听书 + 通勤伴听**，别指望占据他的主动娱乐时间；资源投放上 3-9 岁才是主战场，建议产品侧明确"9-12 岁做留存不做获客"的策略取舍。

## 五、方向性建议（超出单点功能）

1. **把"哄睡"和"通勤伴听"做成两个场景化入口**，而不只是内容分类。3-5 岁的第一付费理由是哄睡，7-12 岁的高频场景是车上/睡前听书——首页顶部可按时间段（晚 8 点后自动浮现"睡前专区"）做轻场景化。

2. **年龄分层是贯穿性架构，不是修饰**。L1-L6 分级已存在于内容侧，建议升级为产品侧"档案驱动"：首页构成、播放器控件复杂度、挑战难度、视觉成熟度、话术语气全部读档案年龄。这是本次 20 人走查中跨越最多画像的共性结论（P1/P10/K1/K9/K10）。

3. **免费策略建议尽快收口（O-1）**：推荐"每学科前 N 免费 + 章回前 3-5 回免费 + 分享获限免"三件套，兼顾体验完整性、转化钩子与裂变；教学的前 10% 免费口径保持不变。

4. **信任体系做成显性页面**：无广告承诺、内容审核机制说明、儿童隐私保护说明、读音报错入口，聚合为家长中心"安心中心"一页。对儿童产品，家长的信任建设与内容质量同权重。

5. **IP 资产变现路径**：13 角色 × 1,668 立绘是重资产，当前主要消耗在教学播放器。建议排期：角色当学科向导（P2）→ 个性化点名故事中角色与孩子同框（19 号已规划，好方向）→ 角色贴纸/周边（P3）。差异化叙事（00 §8）需要产品功能兑现，否则只是 PPT 优势。

6. **9-12 岁做留存不做获客**：K10 的反馈提示年龄上限的天然天花板。营销与内容投入以 3-9 岁为主战场，10-12 岁靠章回听书 + 搞笑/青春内容自然留存即可，避免为高龄段做重投入。

7. **建立"用户反馈 → 内容修复"闭环**：AI 生成内容 + 机审的模式下，上线后真实用户就是最大的审核团队。播放器报错入口 + 后台聚合 + 修复回流（重生成 TTS/修文本）应作为运营基础设施在 MVP 后第一时间补上。
