## 1. 需求总览

### 1.1 产品目标

| 目标 | 衡量指标 |
|:--|:--|
| 内容可播放 | 所有故事/歌曲/教学内容可在小程序内流畅播放 |
| 导航清晰 | 用户3次点击内到达任意内容 |
| 体验沉浸 | 教学/成长内容支持字幕+场景+立绘联动，歌曲支持歌词高亮，故事支持封面纯听 |
| 学习闭环 | 四级朋友养成(未遇见→已相识→好朋友→好伙伴)，可直接挑战跳过收听 |

### 1.2 用户故事

#### 儿童用户故事
```
US-001: 作为一名5岁的孩子，我想听品格故事，这样我能学会勇敢和诚实
US-002: 作为一名7岁的孩子，我想跟唱儿歌，这样我能学英语单词
US-003: 作为一名6岁的孩子，我想看识字动画，这样我能学会认字
US-004: 作为一名8岁的孩子，我想听三国演义，这样我能了解历史
US-005: 作为一名4岁的孩子，我想听摇篮曲，这样我能安心入睡
US-006: 作为一名孩子，我想在学习内容里看到酷酷和桃子的立绘在说话，这样我觉得学习更生动
```

#### 家长用户故事
```
US-101: 作为家长，我想查看孩子的成长进度，这样我能了解他在学什么
US-102: 作为家长，我想收藏孩子喜欢的故事，这样能快速找到再听
US-103: 作为家长，我想通过微信分享故事给朋友，这样能推荐好内容
US-104: 作为家长，我想设置定时关闭，这样孩子听着听着能自动停止
US-105: 作为家长，我想为多个孩子分别建立档案，这样能分别追踪成长进度
```

#### 2.4.2 学习模式与入口

| 需求ID | 需求描述 | 验收标准 |
|:--|:--|:--|
| ED-008 | 顺序学习 | 按课程顺序逐个学习，学完一个字/词进入下一个 |
| ED-009 | 自选组合 | 用户自选字/词组合学习；英语按分类引导（水果/职业/动物等） |
| ED-009a | 智能复习 | 朋友册中筛选“待巩固”的字/词，点击进入收听或直接挑战 |
| ED-009b | 直接挑战 | 所有字/词均可直接进入挑战，不必先收听。挑战通过即代表结交朋友，跳过收听环节 |

> **学习1/学习2/学习3 是独立关系，非线性流程：**
> - **学习1** = 新学，完成后自动进入普通挑战
> - **学习2** = 独立复习章节（不同角度），完成后自动进入普通挑战
> - **学习3** = 独立复习章节（不同角度），完成后自动进入普通挑战
> - 学习2和学习3互相独立，没有先后顺序
> - **可直接挑战**：任何字/词均可跳过收听直接进入挑战，通过即与该字/词成为朋友
>
> **付费边界**：
> - **课程**：每学科按课程编号排序，前10%课程免费体验（含该课程的学习1/2/3全部内容），其余课程需会员解锁。
> - **朋友等级**：所有用户（含免费用户）收听内容/完成普通挑战后等级正常变化（未遇见→已相识→好朋友），等级数据不受会员状态限制。
> - **朋友系统展示**：朋友收集册查看、综合挑战入口、成就贴纸为会员门控——免费用户看到锁定预览+开通提示。因综合挑战需会员，免费用户最高只能达到"好朋友"等级。
> - **普通挑战**：全部免费开放，不受会员限制。

#### 2.4.4 习题与挑战系统

**普通挑战设计：**

| 需求ID | 需求描述 | 验收标准 |
|:--|:--|:--|
| ED-025 | 挑战触发 | 学习1/2/3播放完成后自动进入挑战；也可从朋友册直接进入挑战 |
| ED-026 | 习题类型 | 识字3类题型：听音选字(sound_to_char) / 看字选拼音(char_to_sound) / 看字选组词(char_to_word)；英语有独立题型但同样按1X/2X/3-9X分类结构；拼音无习题 |
| ED-027 | 出题策略 | 每次挑战随机选4题：1道听音选字 + 1道看字选拼音 + 2道看字选组词，覆盖全部3种题型 |
| ED-027a | 出题抽取 | 纯随机从对应题型池中抽取，**不记录已出过的题号**（可能重复出同一题）；与 02 号架构 used_question_ids 字段已废弃、3 号 §3.4.2 纯随机口径一致 |
| ED-028 | 答题反馈 | 答对鼓励动画；答错直接给正确答案。★ 无惩罚·可无限重试：整套挑战（4题）未通过时始终可“再试一次”（每次重新随机出4题），直到通过为止 |
| ED-029 | 通过标准（按学科区分） | **识字**：1X(听音选字)必须对 **且** 3-9X(看字选词)至少1道对 → 通过（2X看字选拼音可错）；**英语**：1X必须对 **且** 2X必须对 **且** 3-9X至少1道对 → 通过；**拼音**：无习题，不考虑通过标准。通过则该字/词成为好朋友（test_passed=true） |
| ED-030 | 未通过处理 | ★ 无惩罚·可无限重试：未通过始终可“再试一次”（重新随机出4题）；也可选“看学习2/3”（会员功能，其他角度~5min）或“下次再来”退出。任何未通过都不降级、不扣分 |
| ED-030a | 上次未通过提示 | 下次进入该字/词时，若上次挑战未通过，显示提示“上次挑战未通过，继续加油！” |
| ED-031 | 进度显示 | 进度条显示：未遇见→已相识→好朋友→好伙伴（四级朋友标识） |

**综合挑战设计：**

| 需求ID | 需求描述 | 验收标准 |
|:--|:--|:--|
| ED-032 | 综合挑战触发-自动 | 攒满10个test_passed=true的字/词，系统自动触发综合挑战 |
| ED-032a | 综合挑战触发-主动 | 用户可主动选择字/词进行综合挑战：可选"未过综合挑战的字"或"所有字"（无论朋友等级） |
| ED-033 | 综合挑战出题 | 10个字/词，每字按该字的题型结构出题（覆盖1X/2X/3-9X），逐字判定是否掌握 |
| ED-033a | 综合挑战逐字判定标准（按学科区分） | **识字**：1X（听音选字）必须对 **且** 3-9X（看字选词）全对 → 该字算通过。2X（看字选拼音）出现但不纳入通过判定——选拼音属于熟悉程度确认，非掌握验收项；**英语**：1X+2X+3-9X **全对** → 该字算通过；10个字中8个通过即综合挑战通过 |
| ED-034 | 综合挑战通过标准 | 10个字/词逐字判定（标准见ED-033a），8/10字通过即综合挑战通过，通过的字/词成为好伙伴 |
| ED-035 | 综合挑战未通过 | **只升不降**：答错的字/词保持原等级（不回落），答对的成为好伙伴。可无限重试，或继续学新字等下次自动触发 |

#### 2.4.5 四级朋友养成系统（层级覆盖）

> **核心原则：朋友等级是层级覆盖关系，高等级包含低等级。达到高等级即代表低等级也满足。本节为展示话术口径，后端 `current_stage` 字段保留，详见 [13-陪伴养成系统设计](13-陪伴养成系统设计.md)。**

> **字词养成适用范围（决策 R7）**：四级朋友养成只针对**教学字词内容**（识字/英语/拼音）以及天然绑定单字/单词的识字故事、英语故事；普通故事/歌曲仅作内容消费，**不驱动字词养成、不需抽取字词索引**（对齐 [16-内容编排方案](16-内容编排方案.md) L0/L0′）。

| 朋友等级 | 名称 | 完成条件 | 颜色标识 |
|:--|:--|:--|:--|
| level0 | 未遇见 | 初始状态，从未收听也从未挑战 | ⚪ 灰色 |
| level1 | 已相识 | 听过学习1（或学习2/3），或直接挑战通过自动跳过 | 🟡 黄色 |
| level2 | 好朋友 | 普通挑战通过（标准按学科区分，见ED-029） | 🔵 蓝色 |
| level3 | 好伙伴 | 综合挑战通过（8/10），代表该字/词已牢固掌握 | 🟢 绿色 |

**朋友等级晋升规则：**

| 操作 | 等级变化 | 说明 |
|:--|:--|:--|
| 完成学习1/2/3 | →已相识（如当前低于已相识） | 听过即标记，但不影响已达到的更高等级 |
| 直接挑战通过 | 未遇见→好朋友 | 跳过收听直接挑战，通过即成为好朋友（隐含已相识也满足）；后端同时设置 current_stage=2 和 study1_completed=true，保证数据一致性 |
| 收听后挑战通过 | 已相识→好朋友 | 正常学习流程 |
| 综合挑战通过 | 好朋友→好伙伴 | 10字综合挑战8/10通过，全部成为好伙伴 |

**朋友等级只升不降规则：**

| 场景 | 等级变化 | 说明 |
|:--|:--|:--|
| 好伙伴的字在综合挑战中未通过 | 保持好伙伴 | **只升不降**，不回落；可再次挑战 |
| 好朋友的字在普通挑战中未通过 | 保持好朋友 | 不回落，无惩罚·可无限重试 |
| 未遇见/已相识的字挑战未通过 | 保持原等级 | 不回落，无惩罚·可无限重试 |

> **说明**：★ 朋友等级**只升不降**，任何挑战未通过都不降级。普通挑战无惩罚、可无限重试（未过始终可“再试一次”）；综合挑战答错的字保持原级、答对才晋升好伙伴。

#### 2.4.6 （已下线）久别重逢/间隔复习

> 本版本**已移除**间隔复习/久别重逢机制（无“想念中”状态、无 needs_review/review_due 字段、无复习接口），与“只升不降·无惩罚”一致。以 [13-陪伴养成系统设计](13-陪伴养成系统设计.md) 为准。
