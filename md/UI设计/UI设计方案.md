## 1. 设计原则

### 1.1 儿童友好优先

- **大圆角**: 所有卡片、按钮使用 8~24px 圆角，营造亲切感
- **大按钮**: 点击区域 ≥ 44pt，适应儿童粗手指操作
- **高对比度**: 文字与背景对比度 ≥ 4.5:1，确保可读性
- **色彩温暖**: 避免冷灰色调，使用暖色传递安全感和愉悦感
- **减少焦虑**: 不做打卡、连续天数等压力型设计，陪伴养成系统纯展示型

### 1.2 家长信任感

- **简洁专业**: 家长中心页面清爽、信息层级清晰
- **数据可视化**: 成长进度用图表和颜色直观展示
- **无广告**: 全产品无广告干扰，家长中心不推销儿童产品

### 1.3 内容为核心

- **封面驱动**: 故事、歌曲、学科都以封面图为视觉中心
- **沉浸式播放**: 播放器极简设计，让内容说话
- **立绘互动**: 教学模式下角色立绘作为视觉焦点，增强代入感

### 1.4 响应式设计

**设计尺寸范围**: 375px ~ 1024px（手机竖屏 ~ iPad Pro横屏）

| 设备类型 | 屏幕宽度 | 布局调整策略 |
|:--|:--|:--|
| iPhone SE | 375px | 基准设计尺寸，按设计稿实现 |
| iPhone 14 Pro | 393px | 微调间距，基本不变 |
| iPhone 14 Pro Max | 430px | 卡片宽度增加10%，网格列宽自适应 |
| iPad Mini | 768px | 学科网格从2列变为3列，播放器保持竖屏 |
| iPad Air | 820px | 教学播放器固定横屏，左插图区55% |
| iPad Pro | 1024px | 教学播放器横屏，左插图区最大60% (600px) |

**教学播放器横屏适配规则**：

| 设备 | 左侧插图区 | 右侧字词区 | 底部控制栏 |
|:--|:--|:--|:--|
| 手机竖屏 | - | - | - （提示旋转设备） |
| 手机横屏 | 50% | 40% | 10% |
| iPad Mini | 55% | 38% | 7% |
| iPad Pro | 60% (max 600px) | 35% | 5% |

**通用适配原则**：
- 所有间距使用相对单位（rem/%），不用固定px
- 图片使用 `object-fit: contain` 保证不变形
- 文字字号在小屏幕上不低于 16px

### 1.5 无障碍设计（Accessibility）

**设计目标**：让视力障碍、色盲、行动不便的用户也能正常使用产品。

#### 字体大小规范

| 层级 | 最小字号 | 说明 |
|:--|:--|:--|
| 辅助文字 | ≥ 14px | 标签、时间、数量等 |
| 正文 | ≥ 18px | 描述文字、分类名称（儿童可读性） |
| 标题 | ≥ 24px | 页面标题、卡片标题 |

**系统字体缩放支持**：
- ✅ 支持微信小程序设置 → 通用 → 字体大小
- ✅ 支持 iOS/Android 系统级字体放大
- ✅ 所有字号使用相对单位（rem），自动跟随系统设置

#### 颜色对比度

**标准要求**：文字与背景对比度 ≥ 4.5:1（WCAG AA 标准）

| 组合 | 对比度 | 状态 |
|:--|:--|:--|
| 主文字 #2D3142 on 背景 #FFF9F0 | 12.8:1 | ✅ 优秀 |
| 次要文字 #8B8D9E on 背景 #FFF9F0 | 5.2:1 | ✅ 合格 |
| 白色文字 on 主色 #FF8C42 | 4.6:1 | ✅ 合格 |

**色盲友好设计**：
- ✅ 四级朋友养成色已通过 Color Oracle 验证
- ✅ 不单独依赖颜色传达信息（配合图标/文字标签）
- ✅ 四级朋友养成色：⚪灰 🟡黄 🔵蓝 🟢绿，色盲可区分

#### 触摸目标

| 元素类型 | 最小尺寸 | 说明 |
|:--|:--|:--|
| 按钮 | 44×44pt | 适应儿童粗手指 |
| 图标按钮 | 48×48px | 播放按钮80px |
| 列表项 | 高度 ≥ 55px | 保证点击区域充足 |
| 按钮间距 | ≥ 8px | 防止误触相邻按钮 |

#### 其他无障碍要求

- ✅ 所有图片必须有 alt 文本（装饰性图片用空alt）
- ✅ 表单元素必须有 label 或 aria-label
- ✅ 焦点顺序符合视觉顺序（Tab键导航）
- ✅ 动画持续时间 ≤ 5秒，提供暂停选项

### 3.3 故事播放器 (Story Player)

> **对应稿**: [酷酷UI设计稿.html](酷酷UI_融合版_v4.html) · 屏 PL-01

**布局结构 (竖屏)**:

```
┌──────────────────────────────┐
│  ↓      一丘之貉        ⋮   │  ← 收起 + 标题 + 更多
├──────────────────────────────┤
│                              │
│      ┌────────────┐         │  ← 封面图 (正方形, 居中)
│      │            │         │  尺寸: W - 80px, 圆角30px
│      │    🦊      │         │  显示故事封面或学科封面
│      │            │         │
│      └────────────┘         │
│                              │
│         一丘之貉            │  ← 故事标题 (28px Bold)
│    上下五千年 · L6 · 9分钟  │  ← 信息行 (20px 次要色)
│                              │
│  ─────────⚪──────────      │  ← 进度条
│  02:15              09:08   │
│                              │
│     ⏮    ▶    ⏭            │  ← 控制区
│   上一段  播放  下一段       │  播放按钮: 80px 圆形(主色)
│                              │  上下段: 50px 圆形(白底)
│  ♡收藏  ↗分享  ⏰定时  📋列表 │  ← 功能按钮行
├──────────────────────────────┤
│  📖  🎵  🌱  👪             │  ← 底部Tab (可收起或覆盖)
└──────────────────────────────┘
```

**设计要点**:
- 纯听模式，无字幕、无立绘，聚焦封面和音频

- 封面区域支持左右滑动切歌 (故事集内自动下一条)
- 定时关闭: 15/30/45/60/90 分钟挡位 + 自定义输入
- 断点续播: 下次进入恢复上次播放位置，有 toast 提示

- **场景**: 上下五千年 E3/E4 等 `mixed` 结构分类
- **布局**: 头图 → 三个分组 (章回作品/独立故事/合集)，每组有自己的标题和色条
- **要点**: 分组标题使用大字号 + emoji 前缀，组间有充足间距避免混淆

### S-06 多层分类页

> **查看设计稿**: [酷酷UI设计稿.html](酷酷UI_融合版_v4.html) · 屏 19-S-06

- **场景**: 双界之门等 `multi_level` 结构，需要继续展开子分类
- **布局**: 学科头图 → 子分类列表 (同学科详情页但用于子分类)
- **要点**: 列表项样式与学科页分类列表一致，保持导航一致性

### G-06 挑战结果页

> **查看设计稿**: [酷酷UI设计稿.html](酷酷UI_融合版_v4.html) · 屏 20-G-06

- **场景**: 普通挑战/综合挑战完成后
- **布局**: 结果状态 (通过/未通过) → 答题回顾 → 角色鼓励语 → 贴纸奖励 → 操作按钮
- **要点**: 通过时展示 🎉 + 绿色状态，未通过时展示鼓励语 + 三选项 (复习/下次/重试)

### GL-02 迷你播放栏

> **查看设计稿**: [酷酷UI设计稿.html](酷酷UI_融合版_v4.html) · 屏 21-GL-02

- **场景**: 全局常驻，除播放器全屏页外所有页面底部显示
- **布局**: 小封面图 + 标题/副标题 + 播放/暂停按钮 + 展开箭头
- **要点**: 高度 70px，叠加在 Tab 栏上方，点击展开对应全屏播放器

### M-03 歌曲列表页

> **查看设计稿**: [酷酷UI设计稿.html](酷酷UI_融合版_v4.html) · 屏 22-M-03

- **场景**: 选择语言子分类后进入的歌曲列表
- **布局**: 分类标题 + 歌曲列表，每条目有封面占位 + 歌名 + 时长 + 播放按钮
- **要点**: 当前播放歌曲高亮显示，条目可滑动收藏/分享

### G-02 课程列表页

> **查看设计稿**: [酷酷UI设计稿.html](酷酷UI_融合版_v4.html) · 屏 23-G-02

- **场景**: 成长 Tab → 选择识字/英语/拼音后进入
- **布局**: 等级统计卡片 (四级堆叠) → 筛选标签 (全部/待巩固/未遇见) → 课程列表
- **要点**: 每个字/词左侧有朋友色条，右侧有朋友标签 pill，点击直接进入学习/挑战

### G-03 课程详情页

> **查看设计稿**: [酷酷UI设计稿.html](酷酷UI_融合版_v4.html) · 屏 24-G-03

- **场景**: 点击课程列表中的某个字/词后进入
- **布局**: 大字展示区 (字 + 拼音) → 朋友等级 → 学习1/2/3 入口卡片 → 挑战入口
- **要点**: 学习2/3 标记 VIP 标签，免费用户点击提示开通会员；可直接挑战跳过学习

### U-01~U-05 通用状态页

> **查看设计稿**: [酷酷UI设计稿.html](酷酷UI_融合版_v4.html) · 屏 25-U

- **包含**: 启动页 (品牌 Logo + 版本号)、首次引导 (创建孩子档案)、空状态 (无收藏/无历史)、加载态 (骨架屏)、网络错误 (重试按钮)
- **要点**: 启动页和引导页使用大图标 + 简洁文案；空状态使用大图标居中 + 操作引导；骨架屏与组件圆角一致；错误页使用红色图标 + 重试按钮
