# 15 - 上线合规与资质 Checklist

> **定位**: 微信小程序「酷酷儿童故事」上线前的合规与资质总清单。产品类目为**文娱内容（儿童故事/歌曲）**，**非教育培训、非游戏**。
> **权威源**: 养成系统合规护栏见 [13-陪伴养成系统设计](13-陪伴养成系统设计.md) §1；体验红线走查见 [14-AI用户体验测试方案](14-AI用户体验测试方案.md)。
> **原则**: 任何一项 P0 未达标即**阻塞上线**。

---

## 1. 类目定位（决定所有资质）

| 项 | 结论 | 说明 |
|:--|:--|:--|
| 小程序服务类目 | 文娱-数字内容 / 图书阅读听书 | 按内容属性申报，**不申报教育培训类** |
| 是否游戏 | **否** | 无版号需求；但需守住"不像游戏"红线（见 §4） |
| 是否教育培训 | **否** | 内容为文娱故事/歌曲，非学科课程；守双减红线（见 §4） |

> ⚠️ 类目一旦按文娱申报，产品内**不得**出现学科考试、打分排名、升学相关表述，否则平台会要求转教育类目并追加资质。

---

## 2. 主体与基础资质（P0）

- [ ] 企业营业执照（经营范围含"从事互联网文化活动/数字内容/软件"等）
- [ ] 小程序主体已完成微信认证
- [ ] ICP 备案（小程序/服务器域名，工信部）
- [ ] 若含音视频点播：评估**《网络文化经营许可证》（文网文）** 适用性
- [ ] 若含图书/有声读物出版物：评估**《网络出版服务许可证》** 适用性
- [ ] 软件著作权登记（小程序 + 后端）
- [ ] 服务器域名 HTTPS 证书

---

## 3. 内容合规（P0）

> **审核方式（决策 R6 / 对齐 05 B-10）**：采用 **AI 机审**，非人工逐条审核。文本内容在**生成阶段已内置双重 AI 审核**（生成模型自审 + 内容安全机审），不合规内容无法产出；上线前再过一道**机审全量扫描**。配音环节少量质量问题已通过生成限制策略处理。

- [ ] 全部故事/歌曲/教学文本完成 **AI 机审内容安全扫描**（暴恐/色情/政治敏感/价值观），保留机审报告
- [ ] 儿童向内容分级：符合 3-12 岁适龄，无惊悚/恐怖/不良诱导
- [ ] 内容来源与版权：原创或已获授权，保留授权链路（防侵权）
- [ ] AI 生成内容（故事/立绘/歌曲）标注与合规：符合《生成式AI服务管理办法》要求
- [ ] 建立内容举报与下架通道

---

## 4. 红线自查（P0，最高优先级）

### 4.1 游戏化红线（避免被判定为游戏，触发版号要求）
- [ ] 无对战/PVP/竞技排名
- [ ] 无付费开箱/抽卡/概率道具
- [ ] 无真实货币购买虚拟道具的消费循环
- [ ] 陪伴养成=**内容消费的正反馈展示**，进度唯一来源为听故事/挑战（见 13 号 §1.2）
- [ ] 陪伴养成为纯展示型，无打卡/连续天数/积分兑换/经营模拟

### 4.2 双减/学科培训红线（避免被判定为教育培训）
- [ ] 无学科考试、无升学、无分数排名
- [ ] "挑战"为内容互动确认，**非考试**；结果只做养成正反馈，不打分不排名
- [ ] 家长端只展示"成长进度/四级朋友统计"，不出现"成绩/名次/达标率"

### 4.3 展示层话术红线（体验一致性）
- [ ] 展示层 0 处出现：测试 / 学习阶段 / 出题 / 完课率 / 学科培训 / 打分排名 / 答错扣分
- [ ] 统一使用养成话术：未遇见 / 已相识 / 好朋友 / 好伙伴 / 挑战 / 朋友收集册

---

## 5. 未成年人保护与隐私（P0）

- [ ] 隐私政策与用户协议已发布，明确儿童个人信息处理规则（《个人信息保护法》《未成年人保护法》）
- [x] 代码已要求**监护人主动同意**，服务端保存用户协议/隐私政策/儿童规则版本与时间；协议正文仍待法务定稿
- [x] 代码最小化收集：孩子档案当前只要求昵称，不收集精确位置
- [x] 睡眠定时：支持关闭/15/30/45/60/90 分钟，跨页面生效并持久化
- [x] 家长中心提供定时关闭、协议/隐私和账号注销入口
- [x] API 已按 JWT 用户校验所有 child_id 归属，越权统一 404
- [ ] 生产传输加密、数据库/备份加密、访问审计需在真实云环境部署后验证
- [ ] 协议补齐运营主体、联系方式、保存期限、第三方 SDK 清单并经法务确认；release 门禁在此之前不放行

---

## 6. 支付与会员（若上线会员）（P0/P1）

- [ ] 会员为**内容解锁**（蒙学/诗词/大IP/学习2/3/离线），非虚拟道具氪金
- [ ] 微信支付资质与商户号就绪
- [ ] 自动续费明示、可取消（合规展示）
- [ ] 未成年人支付限制与退款机制

---

## 7. 中危词处置清单（展示层用词审查）

> 以下词非硬红线，但在文娱类目下需谨慎，逐处评估是否改写。

| 词 | 风险 | 处置建议 |
|:--|:--|:--|
| 课程 / 完课 | 偏教育培训 | 展示层优先用"内容/合集"，后端字段可保留；上线前统一评估 G-02/G-03 页 |
| 学习1/2/3 | 会员内容层级，非学科 | 保留，但避免与"考试/达标"绑定表述 |
| 习题 | 偏应试 | 展示层可用"听音选字/趣味挑战"替代 |
| 教学（播放器） | 中性偏教育 | 内部术语可留，展示面向儿童用"跟读/一起玩"类叙事 |

- [ ] 上线前对上述中危词逐处过一遍展示文案，确认不构成"学科培训"暗示

---

## 8. 技术标识符豁免说明

- 后端字段（`current_stage` / `test_passed` / `comprehensive_passed`）、API 路径（`/api/test/single_word`）、CSS token（`stageUnlearned` 等）为**历史技术标识**，不面向用户，**保留不改**。
- 展示层一律通过映射转为养成话术（见 [13 号 §10 术语字典](13-陪伴养成系统设计.md) 与 `design-tokens.json` 的 `friendLevels`）。
