## 2. 索引体系详解

### 2.1 索引层级

```
_global.json (全局索引)
  └── 学科/_index.json (学科索引)
       └── {分类}.json (分类索引)
            └── {分类}_{条目}.json (合集索引, 仅mixed类型)
```

### 2.2 索引加载策略

客户端采用**懒加载**策略，按需获取索引：

```
Step 1: App启动 → 加载 _global.json (缓存到本地)
Step 2: 进入学科 → 加载 学科/_index.json
Step 3: 点击分类 → 加载 学科/{分类}.json
Step 4: 点击故事 → 加载故事目录下的 segments.json
Step 5: 播放 → 加载整曲MP3 + segments.json(字幕/段落信息)
```

### 2.3 本地缓存策略

> **小程序无 `localStorage`**：持久化缓存统一用 **`Taro.setStorage/getStorage`**（小程序底层为 `wx.setStorage`），APP 端同用 Taro API。

| 数据 | 缓存方式 | 过期时间 |
|:--|:--|:--|
| _global.json | Taro.setStorage(小程序) | 24小时 |
| 学科_index.json | Taro.setStorage(小程序) | 24小时 |
| 分类索引JSON | 内存(Map) | 会话内 |
| segments.json | 内存 | 播放期间 |
| 整曲MP3 | 小程序临时文件 | 播放后清除(会员可离线缓存) |
| timeline.json | 内存 | 播放期间 |
| LRC歌词 | 内存 | 播放期间 |
| 透明底立绘 | 小程序图片缓存 | 系统管理 |
| 封面图 | 小程序图片缓存 | 系统管理 |

> **★ 决策变更(v1.1)**: MP3缓存从"分段播放后清除"改为"整曲播放后清除"，会员用户可离线缓存整曲MP3到本地。

### 2.4 structure_type 与前端渲染映射

> 本节为**摘要**；完整字段表、display_as 映射与各类型 JSON 全貌以 [10-索引与封面设计方案](10-索引与封面设计方案.md) 为权威。

```
standalone_collection
  → 读取 {分类}.json
  → 渲染: 推荐区(随机10条) + 全部列表(按序)
  → 点击 story_card → 播放器

chaptered_work
  → 读取 {分类}.json
  → 渲染: 作品信息 + 章节列表(按chapter_index排序)
  → 点击 chapter_item → 播放器(播放该章节)

mixed
  → 读取 {分类}.json
  → 渲染: 按 structure_type 分组
    ├── chaptered 组 → chaptered_card
    ├── standalone 组 → story_card
    └── collection 组 → collection_card
  → 点击 chaptered_card → 加载章回作品索引
  → 点击 story_card → 播放器
  → 点击 collection_card → 加载 {分类}_{条目}.json

multi_level
  → 读取 {分类}.json (或_next_level.json)
  → 渲染: 子分类卡片列表
  → 点击 → 继续展开下一级
```

### 2.5 用户状态与孩子上下文

#### 2.5.1 全局状态

| 状态 | 含义 | 作用范围 |
|:--|:--|:--|
| `userId` | 家长账号ID | 全局 |
| `selectedChildId` | 当前选中的孩子档案ID | 4个Tab共用 |
| `favorites` | 家长账号共享收藏 | 故事/歌曲/教学 |
| `play_history` | 当前孩子的播放历史 | 故事/歌曲/教学 |
| `learning_progress` | 当前孩子的成长进度 | 成长Tab + 家长Tab |
| `comprehensive_tests` | 当前孩子的综合挑战记录 | 成长Tab + 家长Tab |
| `child_achievements` | 当前孩子的成就与朋友册数据 | 家长Tab |

> **统一规则**：
> - `selectedChildId` 为全局共享状态，家长Tab切换孩子后，成长Tab自动切换到同一个孩子
> - `favorites` 按家长账号共享，不区分 `child_id`
> - `play_history / learning_progress / comprehensive_tests / child_achievements` 全部按 `child_id` 隔离

#### 2.5.2 多孩子切换数据流

```
App启动
  │
  ├──→ 静默登录 / 恢复用户态
  ├──→ 拉取孩子档案列表 GET /children
  ├──→ 选中默认孩子 selectedChildId
  │    ├── 优先恢复上次选择
  │    ├── 否则使用第一个孩子
  │    └── 没有孩子时引导创建/跳过
  │
  └──→ 4个Tab共享 selectedChildId

家长Tab切换孩子
  │
  ├──→ 更新全局 selectedChildId
  ├──→ 刷新家长首页汇总/本周/明细
  ├──→ 刷新成长Tab朋友册与想念列表
  └──→ 播放页后续写历史时使用新的 child_id
```

## 3. 三种播放器的数据流

### 3.1 故事播放器数据流（整曲MP3纯听 + 封面图展示）

```
用户点击故事卡片
  │
  ├──→ 加载整曲MP3
  │    ├── 请求 audio/{学科}/{分类}/{故事名}/full.mp3
  │    └── 整曲流式播放(单次请求,无需逐段加载)
  │
  ├──→ 加载封面图 (如有)
  │    └── 显示故事封面图 + 声波动画条
  │
  ├──→ 播放控制
  │    ├── 播放/暂停
  │    ├── 上一段/下一段: 加载segments.json, 按duration_ms累加seek定位
  │    ├── 重听: seek到当前段起始时间
  │    ├── 定时关闭: 设置项(15/30/45/60/90分钟+自定义)
  │    └── 播放队列: 故事集内自动续播 → 集播完后顺序播同类型下一个
  │
  └──→ 全部播放完
       ├── 记录播放历史（写入 selectedChildId 对应的 child_id）
       ├── 埋点 story_complete
       └── 自动播放队列中下一个故事
```

> **★ 三种播放体验明确(v1.4)**:
> - **故事播放器** = 整曲MP3纯听 + 封面图(如有) + 声波动画，**不显示字幕、不显示场景、不显示立绘**
> - **歌曲播放器** = 整曲MP3纯听 + LRC歌词同步高亮滚动
> - **教学/成长播放器** = 合并MP3 + 横屏三面板(字幕+场景+立绘+教学信息)  

### 3.2 歌曲播放器数据流（LRC歌词同步）

```
用户点击歌曲
  │
  ├──→ 获取歌曲信息
  │    ├── 歌曲名: 文件名 (如 "1. 拍拍手 Clap Your Hands")
  │    ├── MP3 URL: generated_stories/瞎编的歌曲/幼儿/双语歌曲/1. 拍拍手.mp3
  │    └── LRC URL: generated_stories/瞎编的歌曲/幼儿/双语歌曲/1. 拍拍手.lrc
  │
  ├──→ 加载LRC歌词文件
  │    ├── 解析LRC格式 (时间标签 + 歌词文本)
  │    │   [00:12.50]拍拍手 拍拍手
  │    │   [00:15.30]大家一起拍拍手
  │    │   ...
  │    ├── 构建时间轴→歌词行 映射数组
  │    └── LRC由Whisper强制对齐生成(生产管道)
  │
  ├──→ 播放MP3
  │    ├── 整曲流式播放
  │    ├── 监听 currentTime → 二分查找当前歌词行
  │    ├── 当前歌词行高亮
  │    └── 歌词自动滚动(当前行居中)
  │
  ├──→ 播放控制
  │    ├── 上一首/下一首 (同分类内切换)
  │    ├── 循环模式切换
  │    ├── 收藏（按家长账号共享）
  │    └── 定时关闭: 设置项(同故事播放器)
  │
  └──→ 歌词缺失降级
       ├── 如果LRC文件不存在 → 显示纯文本歌词(无高亮)
       └── 后台异步触发Whisper生成LRC
```

> **★ 决策变更(v1.1)**:  
> - 歌词从"TXT纯文本解析(按字数估算行切换)"改为"LRC格式精确时间同步"  
> - LRC文件由Whisper本地强制对齐生成(MP3+TXT → LRC)  
> - 首批6,338首歌曲处理,后续新歌自动生成  
> - 保留降级方案: LRC不存在时显示纯文本  

### 3.3 教学播放器数据流（横屏三面板 + 学习1/2/3独立 + timeline.json）

#### 3.3.1 四级朋友养成与学习入口

```
┌─────────────────────────────────────────────┐
│              课程详情页                        │
│                                              │
│  ┌──────────────┐                            │
│  │ 新学 (免费)   │ ← 学习1: 新学知识,完成后进入挑战 │
│  │ 学习1         │                            │
│  └──────────────┘                            │
│                                              │
│  ┌──────────────┐  ┌──────────────┐          │
│  │ 复习(会员)    │  │ 复习(会员)    │ ← 独立关系,非线性 │
│  │ 学习2         │  │ 学习3         │   会员专属,完成后挑战│
│  └──────────────┘  └──────────────┘          │
│                                              │
│  ┌──────────────┐                            │
│  │ 直接挑战      │ ← 可跳过收听直接挑战(免费)    │
│  └──────────────┘                            │
│                                              │
│  进度条: ⚪未遇见 → 🟡已相识 → 🔵好朋友 → 🟢好伙伴 │
│  (四级朋友,层级覆盖: 高等级包含低等级)           │
└─────────────────────────────────────────────┘
```

> **★ 核心决策(v1.3)**:  
> - **四级朋友养成**: 0=未遇见 / 1=已相识 / 2=好朋友 / 3=好伙伴，层级覆盖关系（后端 `current_stage` 字段保留）  
> - **学习1** = 新学（免费），完成后自动进入普通挑战  
> - **学习2/3** = 独立复习章节（不同角度，**会员专属**），完成后自动进入普通挑战  
> - **可直接挑战**: 任何字/词均可跳过收听直接进入挑战，通过即成为好朋友  
> - 学习2和学习3之间无顺序依赖，可任选  
> - 进度条显示四级朋友: ⚪→🟡→🔵→🟢

#### 3.3.2 教学音频合并方案

```
生产管道(离线):
  学习1/sp_00001.mp3 ─┐
  学习1/sp_00002.mp3  ├──→ ffmpeg concat ──→ 学习1/full.mp3
  学习1/sp_00003.mp3 ─┘                         +
                        ──→ 学习1/timeline.json
                            [
                              { "seq": 1, "start_ms": 0,     "end_ms": 21250 },
                              { "seq": 2, "start_ms": 21250,  "end_ms": 26107 },
                              { "seq": 3, "start_ms": 26107,  "end_ms": 35400 },
                              ...
                            ]
                            (上为简化示意；timeline.json 实际为 8 字段完整结构
                             {seq,start_ms,end_ms,duration_ms,segment_id,character,text,voice_id}，
                             以 07 号 §脚本2 / 08 号 §3.2 为权威口径)

客户端播放:
  加载 full.mp3 (单文件整曲播放)
  加载 timeline.json (段落时间戳)
  加载 segments.json (字幕/角色/教学内容)
  
  播放时:
    监听 currentTime → 二分查找 timeline.json → 定位当前段
    切换字幕/立绘/教学内容面板
```

#### 3.3.3 横屏三面板布局数据流

```
用户进入课程学习1 → 强制横屏
  │
  ├──→ 加载数据
  │    ├── segments.json (字幕 + characters[] + 教学内容)
  │    ├── full.mp3 (合并音频)
  │    ├── timeline.json (段落时间戳)
  │    ├── 场景图: illustrations/scence/{location}/
  │    └── 透明底立绘: illustrations/characters_transparent/{角色}/{pose}/{表情}/
  │
  ├──→ 渲染横屏三面板 (560×280)
  │    │
  │    ├── 左面板: 插图区 (占60%宽度)
  │    │    ├── 场景背景图 (铺满)
  │    │    ├── 角色透明底立绘 (叠加在场景上)
  │    │    │    ├── 根据 segments[].characters[] 加载
  │    │    │    ├── 当前说话角色 → 居中 + 全亮
  │    │    │    └── 非说话角色 → 侧边 + 半透明
  │    │    └── 立绘切换: characters[]变化时切换pose/emotion
  │    │
  │    ├── 字幕区: 仅跨左面板底部 (60%宽×30%高,不占用右面板空间)
  │    │    ├── 当前段 text (大字号)
  │    │    ├── 学习字词高亮 (如"红"字加粗变色)
  │    │    └── 角色名标签
  │    │
  │    └── 右面板: 字词信息区 (占40%宽度)
  │         ├── 大字: 当前学习的字/词 (超大字号)
  │         ├── 拼音: hóng
  │         ├── 释义: 红色，像血或太阳的颜色
  │         ├── 组词: 红色、红旗、红军
  │         ├── 例句: 秋天的枫叶是红色的。
  │         └── 笔画动画: 笔顺演示(如有)
  │
  ├──→ 播放控制 (4个按钮)
  │    ├── 上一段: seek到timeline中上一段start_ms
  │    ├── 播放/暂停
  │    ├── 下一段: seek到timeline中下一段start_ms
  │    └── 重听: seek到当前段start_ms
  │    (无跟读、无倍速)
  │
  ├──→ 进度条 (四级朋友)
  │    ├── ⚪未遇见 → 🟡已相识 → 🔵好朋友 → 🟢好伙伴
  │    ├── 当前等级高亮
  │    └── 不显示学习1/2/3的子进度
  │
  └──→ 学习1/2/3完成
      ├── 记录: 在 selectedChildId 对应的 child_id 下更新 study{N}_completed = true, current_stage = max(current_stage, 1)
       ├── 自动进入普通挑战
       └── 挑战未通过 → 3个选项: 再试一次 / 看学习2或3复习(会员) / 下次再来
```

#### 3.3.4 习题与挑战数据流

**普通挑战流程：**

```
学习1/2/3完成 或 用户直接选择挑战
  │
  ├──→ 加载习题 (出题策略: 随机4题,纯随机)
  │    ├── 扫描 习题/ 目录 (16题: 4听音选字 + 4看字选拼音 + 8看字选组词)
  │    ├── 从对应题型池中随机抽取，不跟踪已出题号
  │    ├── 随机选4题: 1道听音选字 + 1道看字选拼音 + 2道看字选组词
  │    │    └── 纯随机，可能重复出同一题
  │    └── 加载 编号{N}/segments.json + verify.json
  │
  ├──→ 渲染习题界面 (逐题展示)
  │    ├── 题目文本 + 选项
  │    └── 提交按钮
  │
  ├──→ 用户作答 (逐题)
  │    ├── 对照 verify.json 验证
  │    ├── 答对 → 鼓励动画 + 下一题
  │    └── 答错 → 直接给正确答案 + 下一题 (该题不重试)
  │
  ├──→ 挑战结果（按学科区分通过标准）
  │    ├── 通过 → test_passed = true, current_stage = max(current_stage, 2)
  │    │    ├── 识字通过条件: 1X对 + 3-9X≥1道对 (2X可错)
  │    │    ├── 英语通过条件: 1X对 + 2X对 + 3-9X≥1道对
  │    │    └── 记录 test_count++, last_test_failed = false, retry_used = 0
  │    └── 未通过 → 给1次重试机会 (retry_used++)
  │         ├── 重试通过 → 算通过 (同上)
  │         └── 重试未通过 → last_test_failed = true, 弹出3个选项:
  │              ├── "看学习2/3复习" (会员) → 播放学习2或3 → 完成后重新挑战
  │              ├── "下次再来" → 退出, 下次进入该字时提示"上次挑战未通过"
  │              └── "再试一次" → 重新随机出4题 (建议不超过2轮)
  │
  └──→ 朋友等级更新
       ├── 未遇见 → 好朋友 (直接挑战通过, 跳过收听)
       ├── 已相识 → 好朋友 (学习后挑战通过)
       └── 好伙伴 → 保持好伙伴 (更高等级不受影响)
```

**综合挑战流程：**

```
综合挑战触发
  │
  ├──→ 自动触发: 当前孩子攒满10个 test_passed=true 的字/词
  │    └── 系统检查 learning_progress WHERE child_id=selectedChildId AND test_passed=true AND comprehensive_passed=false
  │         └── COUNT >= 10 → 自动触发
  │
  ├──→ 主动触发: 用户从朋友册选字
  │    ├── 可选"未过综合挑战的字" (test_passed=true, comprehensive_passed=false)
  │    └── 可选“所有字” (无论等级，选什么考什么)
  │
  ├──→ 出题 (10个字/词, 每字按学科结构出题覆盖1X/2X/3-9X)
  │    └── 记录到 comprehensive_tests 表 (含 per_char_results 字段)
  │
  ├──→ 用户作答 (逐字逐题)
  │    ├── 答对 → 鼓励动画
  │    └── 答错 → 直接给正确答案
  │
  └──→ 综合挑战结果 (逐字判定)
       ├── 识字逐字判定: 1X对 + 3-9X全对 → 该字通过 (2X无所谓)
       ├── 英语逐字判定: 1X+2X+3-9X全对 → 该字通过
       ├── 8/10字通过 → 通过的字/词 comprehensive_passed=true, current_stage=3
       │    └── 记录 comprehensive_tests: passed=true, correct_count=N, per_char_results=[...]
       └── 未通过 → 可重试, 或继续学新字
            └── 朋友等级回落: **只回落答错的字/词** (per_char_results中passed=false的字)
                 → current_stage=2, comprehensive_passed=false
                 → 答对的字/词保持好伙伴
```
