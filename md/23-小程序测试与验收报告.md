## 三、已修复缺陷（12 项）

| # | 缺陷 | 根因 | 修复 |
|:--:|:--|:--|:--|
| 1 | 迷你播放栏被底部 TabBar 遮挡 | `bottom` 定位落在 TabBar 层下 | 改 `top:50%` 垂直居中 |
| 2 | 缩成迷你栏后 TabBar 高度塌一半 | custom-tab-bar 非 fixed | 改 `position:fixed;bottom:0` |
| 3 | 登录页协议字过大、链接色失效 | Taro inline style 的 px 不转 rpx、`var()` 在 inline 失效 | 改走 SCSS 类 `.agree-t/.agree-link` |
| 4 | 设置页「定时触发」文字竖排挤压 | flex 挤压折行 | `white-space:nowrap; flex:none` |
| 5 | 章回故事「最近播放」封面空白 | 章节级路径无专属封面文件 | `guessCoverChain()` 逐级上溯 + `onError` 递进到作品级封面 |
| 6 | 夜间模式多处文字几乎不可见 | 未显式设 color 的文字继承 page 浅色计算值，`.theme-dark` 变量覆盖不到祖先 | `.theme-dark { color: var(--color-text) }` 重申继承 |
| 7 | 播放历史无分组 | 与 md/09 C-04「按今天/昨天分组」不符 | 实现 今天/昨天/更早 三段分组 |
| 8 | 超长搜索词把整串回显占满 5 行 | 空态文案直接拼接 keyword | 超 12 字截断加 `…` |
| 9 | 章回作品页坏参数显示「章回作品 · 0 章」空壳头 | 加载失败仍渲染 banner | `!error &&` 条件渲染 |
| 10 | **播放正常却提示「故事加载失败了」** | `loadFailed` 混淆了「分段索引缺失」与「音频播不了」，且成功后不清除 | 拿到有效时长即自动撤销提示（`loadFailedRef` + onTimeUpdate） |
| 11 | 辅助文字对比度 3.13:1 低于 WCAG AA | `--color-text-secondary: #8B8D9E` 过浅 | 浅色改 `#6E7080`（4.67:1）、夜间改 `#A0A9CE`（5.63:1）、循环胶囊文字 `#6E4FB0`（6.16:1） |
| 12 | 6 处触控热区 < 88rpx | 文字型控件无纵向 padding | `.sbtn` 88rpx、`.share-bar/.htag/.sec-h .m/.seg .s/.loop-pill` 加纵向 padding 撑热区 |

## 五、已知设计取舍（非缺陷，供决策）

| 项 | 现状 | 说明 |
|:--|:--|:--|
| 迷你浮球与右侧圆键部分重叠 | 浮球 45×45 居中偏右，与「最近播放」卡的播放键有 ~18px 重叠 | 位置由用户明确指定（"放到中间高度"）；浮球有 ✕ 可关。若需彻底避开，可改为拖拽或贴边半隐藏 |
| 三播放器主控键尺寸不一致 | 故事 81px / 歌曲 76px / 教学 52px | 教学播放器为横屏物理像素体系，与竖屏 rpx 体系不可直接比较；竖屏两者差 5px 属视觉容差 |
| 内联 px 93 处 / 硬编码色值 34 处 | 主要在成长线与家长线页面 | Taro 下 inline style 的 px 不转 rpx，但这些页面按 px 设计且实测视觉正常；改动风险大于收益，暂记录不改 |
| `Icon` 组件 2 处 Image 无 ariaLabel | ariaLabel 覆盖率 95.5%（44 个 Image 中 2 个） | 矢量图标装饰性元素，可接受 |
| 播放器控制键保留矢量图标 | 未换插画图标 | 插画图标在 40px 尺寸下细节糊，矢量更清晰 |

## 六、复现与回归方式

```powershell
cd 项目\酷酷儿童故事\miniapp

# 1 构建
$env:NODE_ENV='production'; $env:TARO_APP_USE_MOCK='false'; npm run build:weapp

# 2 重载 IDE（close --project → auto，会重新编译）
node scripts\ide-launch.cjs

# 3 按需跑
node scripts\weapp-walk-all.cjs all      # 全页面走查
node scripts\weapp-walk2.cjs a           # 深度交互
node scripts\weapp-chaos.cjs a           # 破坏性
node scripts\weapp-nitpick.cjs           # 量化度量（热区/对比度）
node scripts\weapp-sharebar-verify.cjs   # 分享入口
```

前置：后端 `server` 已启动（`http://localhost:3000/api/v1/health` 返回 200）。
