## 0. 一句话定位

**酷酷是"听故事 + 唱歌曲 + 学知识"的儿童文娱内容产品。** 陪伴养成系统（**四级朋友 + 朋友收集册**）是**鼓励孩子多听内容的轻量正反馈层**，不是游戏。孩子每和一个字/词从"未遇见"到"好伙伴"，就像交到一个新朋友——用交朋友的叙事，把掌握程度自然可视化。

---

## 1. 合规红线与护栏（最高优先级）

### 1.1 类目定位
- **文娱内容类目**（数字阅读 / 故事音频 / 儿童内容），**非在线教育**、**非游戏**。
- 全站**无**"测试 / 学习阶段 / 出题 / 完课率 / 学科培训 / 打分排名"等教育评测话术。
- 全站**无**游戏化对抗玩法，不触发游戏版号（ISBN）。

### 1.2 六条护栏（任何改动必须同时满足）
1. **进度唯一来源 = 消费内容**（听故事、学字词、完成挑战）。不消费内容进度不动 → 所有设计 100% 服务于"促进听内容"。
2. **会员门控（展示层）** — 免费用户等级正常变化（消费内容即涨等级，不受会员状态限制）；朋友收集册查看、综合挑战入口、成就贴纸为会员专属展示。免费用户看到锁定预览+开通提示，形成转化钩子。普通挑战全部免费。无虚拟货币/氪金/积分兑换。
3. **无对抗**：无战斗、无关卡闯关、无 PVP、无竞技排行。
4. **纯展示型正反馈**：只有鼓励语 + 成就贴纸 + 朋友册可视化，**不做打卡、不做连续天数、不做积分兑换、不做经营模拟**。
5. **内容永远是主体**：首页是故事 / 歌曲，成长可视化放"成长"Tab 二级页；比重上内容为主、养成为辅。
6. **睡眠定时**：提供"定时关闭"（睡眠功能），到点自动停止播放，帮助孩子入睡；不做强制用时管控/防沉迷限制。

### 1.3 话术替换总表（全局强制）

| 旧（教育评测，禁用） | 新（陪伴叙事，采用） |
|---|---|
| 测试 / 考试 / 测验 | 挑战 |
| 学习阶段 / 掌握度 | 熟悉程度 / 朋友等级 |
| 未学 | 未遇见 |
| 已学 | 已相识 |
| 测试通过 | 好朋友 |
| 综合掌握 / 已掌握 | 好伙伴 |
| 掌握了 N 个字 | 交到了 N 个字朋友 |
| 课程 / 完课率 | （删除，不使用） |
| 错题 / 答错扣分 | （删除，答错无惩罚） |

## 2. 四级朋友体系

孩子和每一个"字 / 词"的熟悉程度，用交朋友的叙事表达。**颜色沿用 UI 设计稿的四级色（不变）**：

| 等级 | 名称 | 含义 | 达成条件 | 颜色 | 令牌 |
|---|---|---|---|---|---|
| 0 | 未遇见 | 还没接触过 | — | `#D1D5DB` 灰 | `stage.unmet` |
| 1 | 已相识 | 听过一次 | 首次收听关联字/词 | `#FFD93D` 黄 | `stage.met` |
| 2 | 好朋友 | 普通挑战通过 | 普通挑战通过（或直接挑战通过） | `#6BCBFF` 蓝 | `stage.friend` |
| 3 | 好伙伴 | 综合挑战通过 | 综合挑战通过 | `#7ED957` 绿 | `stage.bestie` |

> **关键**：朋友等级由**里程碑达成情况**驱动（首次收听 / 普通挑战 / 综合挑战），**层级覆盖**——高等级即代表低等级也满足。后端以 `current_stage` 字段（0/1/2/3）记录，展示层统一用养成话术。

---

## 3. 进度规则（里程碑驱动）

### 3.1 三个里程碑 → 三级晋升

一个字/词的朋友等级由三个里程碑逐级点亮，**不设任何虚拟货币/积分**：

| 情景 | → 朋友等级 |
|---|---|
| 第一次听（关联该字/词的内容） | 已相识 |
| 听过后 · 普通挑战通过 | 好朋友 |
| 普通后 · 综合挑战通过 | 好伙伴 |

### 3.2 直接挑战（可跳过收听）

- 所有字/词均可**直接进入挑战**，不必先收听。
- **直接**普通挑战通过 → 直接标记**好朋友**（等价补齐“已相识”）。
- 后端处理：直接挑战通过时，同时设置 `current_stage=2` 和 `study1_completed=true`，确保后续“是否收听过”查询一致。
- **直接**综合挑战通过 → 直接标记**好伙伴**。
- 走哪条路最终等级一致，直接挑战**不吃亏也不占便宜**。

### 3.3 答错与回落

- **答错**：不扣任何东西、可重试、可跳过，**无任何惩罚**。普通挑战未通过给 1 次重试机会，重试通过即通过。
- **朋友等级回落**：综合挑战未通过时，**只回落答错的字/词**（好伙伴 → 好朋友），答对的保持好伙伴。不连坐。

### 3.4 久别重逢（轻量间隔重复）

- 好伙伴超 **14 天（可配）** 未再见，自动标记"想念中"（仅提醒，不降级）。
- 再次挑战通过 → 刷新时间、消除"想念中"；未通过 → 回落好朋友。
- 只做温和提醒，**不做打卡任务、不做连续天数**。

## 4. 朋友收集册（掌握度可视化）

养成不"氪金"、不"打分"，但**掌握度不丢**，全部体现在朋友收集册里：

- **朋友收集册**：按学科（识字 / 拼音 / 英语…）罗列所有字/词及其朋友等级（颜色标识）。
- **"好伙伴"数量 = 最硬的掌握指标**（综合挑战通过 = 真正掌握）。
- 点进任一字/词可看它的朋友等级、几时相识、挑战记录。
- 支持按学科筛选，可筛“全部 / 想念中 / 未遇见”。
- **筛选定义**：待巩固 = 已相识(stage=1) + 好朋友(stage=2)，即已开始接触但尚未达到好伙伴的字/词；未遇见 = stage=0。
- 家长端可按学科查看"交到多少好伙伴 / 好朋友"，即掌握了哪些、多少。
- 定位为**中性收集统计**，非"成绩单 / 排名"，规避教育评测属性。

---

## 5. 陪伴养成正反馈（轻量、纯展示型）

给孩子即时正反馈，但**绝不制造压力**：

- **角色鼓励语**：酷酷 / 桃子等角色立绘 + 一句鼓励（如"你和『勇』成为好朋友啦！"）。
- **成就贴纸**：交到 N 个好伙伴、集齐某学科等，发一张纪念贴纸（纯收藏，无兑换）。
- **朋友册可视化**：四级色进度一目了然。
- **明确不做**：不打卡、不连续天数、不积分兑换、不经营模拟、不排行榜。

---

## 6. 变现

- **只内容收费**：会员解锁更多故事 / 歌曲 / 知识内容。
- **朋友系统会员门控（展示层）**：朋友收集册查看、综合挑战入口、成就贴纸为会员专属展示，不设付费虚拟货币。免费用户等级正常变化（消费内容即涨，不受会员状态限制），看到锁定预览+开通提示。普通挑战免费开放。

## 7. 美术与技术方案

### 7.1 能力家底（已核实）

| 环节 | 能力 | 结论 |
|---|---|---|
| 角色立绘 | dreamina（即梦）文生图 | ✅ 具备 |
| 角色一致性 | IP-Adapter 锁定角色特征 | ✅ 具备（需调参） |
| 成就贴纸 | dreamina 文生图 + 分龄插画规范 | ✅ 直接可用 |
| 素材托管 | 后端服务 + /images | ✅ 有基础 |
| 前端渲染 | Taro 3 + React 小程序 | ✅ 具备 |

### 7.2 美术清单（精简）
- **角色立绘**：酷酷 / 桃子等既有角色，用于鼓励语场景（复用现有立绘）。
- **成就贴纸**：一批 2D 贴纸插画，dreamina 生成，风格遵循 `制度/儿童插画指导规范.md`，暖色圆润手绘风。
- **朋友册 UI**：纯前端组件（四级色 + 卡片），无额外重美术。
- 不做 3D、不用游戏引擎（合规 + 复用现有 2D 能力）。

## 9. 风险与短板（诚实记录）

- **合规主观性**：任何"养成"元素堆多都可能被判"游戏化过重"→ 严守 §1.2 护栏，纯展示、内容为主。
- **成就贴纸产能**：批量插画需精修挑图，分批产出即可。
- **朋友册性能**：字词量大时列表需分页 / 懒加载，防低端机卡顿。
