# 21 - 资质办理操作手册（个体工商户版·北京属地·照抄可办）

> **定位**: 「酷酷儿童故事」全部资质/备案的**逐步骤·逐页面·逐字段操作手册**，每一步给出"在哪操作 → 填什么 → 怎么说"，字段值可直接复制。与 [17-合规资质备案执行指南](17-合规资质备案执行指南.md) 互补——17 号讲"办哪些、什么顺序"，本文讲"每一步具体怎么填"。
> **属地口径**: 经营者属地为**北京**，本文所有"去哪办"均按北京入口给出（e窗通/各区政务服务中心/北京通信管理局/市文旅局）；⚠️ 北京特殊点：**普通住宅不能登记为经营场所**，解法见 §1.3。
> **主体结论（2026-07 评估）**: 采用**个体工商户**主体即可完成全部必办项（执照/ICP备案/小程序备案/认证/支付/虚拟支付/软著）。文网文、网络出版许可证个体不可办，但按本文类目策略**大概率无需办理**（见 §10、§11）。
> **重要提醒**: 各平台页面与材料要求会更新，**以办理时官方页面提示为准**；本文字段实例按当前页面整理，若页面字段有出入，按语义对应填写。

## 0. 开始前：准备清单与占位符约定

### 0.1 占位符约定

本文所有需要你本人信息的地方用【】标注，办理时替换：

| 占位符 | 说明 |
|:--|:--|
| 【姓名】 | 你的身份证姓名（=个体户经营者=各平台法人/负责人） |
| 【身份证号】 | 本人身份证号 |
| 【手机号】 | 本人实名手机号（全流程用同一个，接验证码） |
| 【邮箱】 | 常用邮箱（建议专门注册一个，全流程统一用） |
| 【字号】 | 个体户名称中的字号，如"酷酷"（若被占用换一个，2-6 字） |
| 【住所】 | 经营场所地址（⚠️北京普通住宅不能登记，解法见 §1.3） |
| 【域名】 | 你注册的域名，如 `kukustory.com` |

### 0.2 材料准备（办任何一项前先备齐）

- [ ] 本人身份证原件（拍照用：正反面，光线充足、四角完整、无反光）
- [ ] 本人实名手机号（能接验证码，办理期间保持畅通——管局会电话抽查）
- [ ] 本人银行卡（Ⅰ类借记卡，微信支付结算用）
- [ ] 邮箱一个
- [ ] 一台带前置摄像头的手机（多处需要扫脸核验）
- [ ] 预算：微信认证 ¥300/年 + 域名约 ¥60/年 + 服务器约 ¥300-600/3个月，合计首期 **¥700-1000**

### 0.3 全流程总览（严格按此顺序，前后有依赖）

```
第1步 个体工商户营业执照（§1）        ← 一切的前提，3-7 天
  ├─► 第2步 买域名+服务器+域名实名（§2）     当天
  │      └─► 第3步 ICP 备案（§3）           最长闸门，拿到执照立刻办
  └─► 第4步 注册小程序（§4）
         ├─► 第5步 小程序备案（§5）          需 ICP 备案号，可与§3串行
         ├─► 第6步 微信认证（§6）
         │      └─► 第7步 微信支付商户号（§7）
         │             └─► 第8步 虚拟支付（§8）
         └─► 第10步 服务类目申报（§10）      ← 决定要不要"大证"的关键步
第9步 软著登记（§9）                  ← MVP 代码能跑后随时办
第11步 文旅局咨询（§11）              ← 随时可打，建议第1周内完成
```

## 1. 第1步：个体工商户营业执照

### 1.1 在哪办（北京）

**线上**（推荐）：电脑打开**北京市企业服务 e 窗通平台** `ect.scjgj.beijing.gov.cn` → 注册/登录（支持"京通"账号）→ 首页选“**开办企业**”→ 主体类型选“**个体工商户**”，全程网办（电子签名用"e窗通"APP 或微信扫码）。手机端可用“e窗通”APP 全流程办。
**线下**：经营场所所在**区的政务服务中心市场监管登记注册窗口**（如东城区政务服务中心：珠市口东大街 12 号；其他区在 `banshi.beijing.gov.cn` 搜"个体工商户设立登记"查本区地址和电话），带身份证+场所材料，窗口人员会帮填。

> 拿不准就打 **010-12345**，说："我想在【区名】办一个个体工商户营业执照，做软件开发的，请问 e 窗通上怎么办，经营场所有什么要求？"也可直接打所在区市场监管局登记注册咨询电话（e 窗通平台公告页有各区电话汇总）。

### 1.2 逐字段填写

| 页面字段 | 填什么（可复制） | 说明 |
|:--|:--|:--|
| 名称（字号+行业+组织形式） | `北京【字号】软件开发工作室` | 例："北京酷酷软件开发工作室"。e 窗通内先走"名称自主申报"查重，被占用就换字号 |
| 组成形式 | `个人经营` | 不选家庭经营 |
| 经营者 | 【姓名】【身份证号】 | 上传身份证正反面照片 |
| 经营场所 | 【住所】 | 见 §1.3 |
| 从业人数 | `1` | |
| 资金数额 | `1万元` | 个体户无实缴要求，随便填个小额 |
| **经营范围** | 见下方整段复制 | **最重要的字段**，决定后续资质口径 |

**经营范围（整段复制，系统一般是勾选式，按下列条目逐个搜索勾选）：**

```
一般项目：软件开发；信息技术咨询服务；数字内容制作服务（不含出版发行）；
动漫游戏开发；数字文化创意软件开发；互联网销售（除销售需要许可的商品）；
广告设计、代理；技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广
```

> - 勾选式系统里逐条搜关键词：`软件开发`、`信息技术咨询`、`数字内容制作`、`数字文化创意`，有哪条选哪条，核心是**必须包含"软件开发"**。
> - "从事互联网文化活动"属**许可项目**，个体户勾了也要办文网文才能真经营，**不要勾**；将来真需要文网文时会换公司主体（见 §11），此处不留坑。

### 1.3 经营场所怎么填（北京重点坑）

北京要求经营场所为**非住宅类规划用途的合法固定场所**（住所承诺制也明确排除住宅），普通商品房住宅**不能**直接登记。

> **已定路线（2026-07-29）**：经营者无商业房产、户籍地（河北）无可用房产，确定采用**石景山区集中办公区托管地址**方案；住宅地址直填已验证会卡在材料上传环节（不动产证用途与表单不符）。

**托管地址采购流程（照做）：**

1. 要官方名单：打 **010-11616611**（市市场监管局登记专线）问"石景山区备案的集中办公区名单及联系方式"；或直接去**鲁谷街道市场监管所**窗口当面问（审材料的就是他们，答案最权威）；兜底：淘宝/百度搜"石景山 注册地址 个体户"
2. 直接联系集中办公区**运营方**签约（不必经电商中介），年费约 ¥600-2000，携身份证+名称预查通知书
3. 下单前四问：①地址在石景山且局里认可？有下证案例？②提供盖章房产证复印件+托管协议+盖章住所证明全套？③驳回退款吗？④后续微信支付/ICP备案用此地址有无问题、续费多少？
4. 拿到材料后回 e窗通改 4 处：住所产权类型→**租赁**；住所产权人→**运营方全称**；房屋用途/地址/面积→照托管材料抄；再在文件上传页传盖章住所证明（坑位1）与房产证复印件+协议（坑位2）

**其他方案（备查）：**

| 方案 | 适用 | 说明 |
|:--|:--|:--|
| 自有/租赁**商业或办公用途**房产 | 手里有商铺/写字楼资源 | 填房产证地址；租赁的传租赁合同 |
| 户籍地自有住宅注册 | 老家有房者（多数省份允许住宅登记个体户） | 本项目经营者老家无房，不适用 |
| 网络经营场所 | 仅限已在电商平台（淘宝/京东等）开网店者 | 自建小程序**不适用**；个体流动商与软件开发行业不匹配，也不可行 |

### 1.4 提交后

- 审核 1-3 个工作日，通过后**电子营业执照**直接在"电子营业执照"微信/支付宝小程序里领取；纸质执照可选邮寄或到登记所在区政务服务中心领。
- **领到执照后马上做两件事**：① 下载电子营业执照（后面每个平台都要传执照照片/扫描件）；② 记下**统一社会信用代码**（18 位，后面反复填）。
- 30 日内办税务登记：搜"**北京市电子税务局**"（`etax.beijing.chinatax.gov.cn`）→ 新办纳税人套餐，个体户小规模季度 30 万以内免增值税，按提示走完即可（不影响后续资质办理，可并行）。

## 2. 第2步：域名 + 云服务器 + 域名实名

> 以腾讯云为例（微信生态同厂，备案联动最顺）。阿里云流程等价。

### 2.1 注册腾讯云账号并企业实名

1. 打开 `cloud.tencent.com` → 注册 → 用【手机号】+【邮箱】注册。
2. 控制台 → 账号中心 → **实名认证** → 选 **企业实名**（个体工商户属企业类）→ 上传营业执照 → 认证方式选"法定代表人人脸识别"→ 用微信扫码刷脸。
3. ⚠️ 必须**企业实名**而不是个人实名，否则后面 ICP 备案主体对不上。

### 2.2 买域名

1. 控制台搜"域名注册"→ 输入想要的名字（建议全拼或英文，如 `kukustory`）→ 选 `.com`（首选）或 `.cn`。
2. 购买时长选 **1 年**（¥60-80），勾选自动续费。
3. **域名信息模板**：新建模板 → 类型选**企业** → 名称填营业执照全称 → 证件选"营业执照（统一社会信用代码）" → 上传执照 → 提交**实名认证**（1-3 天，等它变"已实名"才能备案）。

> 域名起名注意：将来 ICP 备案的"网站名称"与域名无强绑定，域名本身随意；但不要用 `edu`、`school` 等教育字样。

### 2.3 买云服务器

1. 控制台 → 云服务器 CVM（或轻量应用服务器 Lighthouse，更便宜够用）→ 新购。
2. 逐项选择：

| 选项 | 选什么 |
|:--|:--|
| 地域 | **中国大陆任一**（北京、上海均可，选北京延迟更低）——境外机器不能备案 |
| 机型 | 2核4G（对齐 02 号预算） |
| 镜像 | Ubuntu 22.04 LTS 或 Debian 12 |
| 带宽 | 3-5 Mbps 起步即可（音频走 CDN/COS，不吃服务器带宽） |
| 时长 | **≥ 3 个月**（备案硬要求） |

3. 买完记下**公网 IP**。

## 3. 第3步：ICP 备案（工信部）——最长闸门，最先办

### 3.1 入口

腾讯云控制台 → 搜"**ICP 备案**"→ 开始备案。全程手机小程序"腾讯云网站备案"也可办。**全程线上，不需要去任何现场**；审核方为**北京市通信管理局**（主体属地按营业执照地址自动归属，无需自己选）。

### 3.2 逐字段填写

**① 主体信息页**

| 字段 | 填什么 |
|:--|:--|
| 主办单位性质 | `企业`（个体工商户选企业类，若下拉里有"个体工商户"则直接选它） |
| 主办单位名称 | 营业执照上的全称，一字不差 |
| 证件类型 | `工商营业执照（统一社会信用代码）` |
| 证件号码 | 18 位统一社会信用代码 |
| 证件住所 | 照抄营业执照上的住所 |
| 通信地址 | 实际能收到函件的地址，精确到门牌号 |
| 法定代表人/负责人 | 【姓名】+【身份证号】+【手机号】+【邮箱】 |
| 应急联系电话 | 可填家人手机号 |

**② 网站（服务）信息页**

| 字段 | 填什么（可复制） | 说明 |
|:--|:--|:--|
| 服务类型 | `网站` + `APP/小程序`（如有该选项则一并勾） | |
| 网站名称 | `酷酷童话屋` 或 `酷酷故事小站` | 规则见下方⚠️ |
| 域名 | 【域名】 | 需已实名满 3 天以上更稳 |
| 网站内容/服务内容 | `其他` 或 `网络图片/文字/音视频（不含新闻、出版、教育、医疗保健、药品和医疗器械、文化、广播电影电视节目等需前置审批内容）` | 按下拉可选项选最接近"综合门户/其他"的一项 |
| 前置审批项 | **全部选"以上都不涉及"/"无"** | 关键！选了"文化""出版"就会被要求先交许可证 |
| 网站备注 | 见下方可复制文本 | 管局看的说明，主动讲清楚降低电话核查概率 |
| 网站负责人 | 【姓名】（与法人同人即可） | |

**⚠️ 网站名称规则（管局硬性要求）：**
- 3 个汉字以上；不能含"中国、中华、国家"等；**不能含"教育、培训、学校"**；不能是纯域名/纯英文/纯数字；个体户一般不建议直接用"XXX网"这类平台化名称。
- 备选（按顺序试）：`酷酷童话屋`、`酷酷故事小站`、`酷酷童趣屋`。

**网站备注（整段复制）：**

```
本网站为个体工商户自营的原创儿童故事内容展示网站，内容均为自主创作的
儿童故事、儿歌的文字与音频介绍，不含新闻、出版、教育培训、医疗、游戏
等需前置审批的内容，不提供用户发帖等互动功能，不含经营性信息服务。
```

**③ 真实性核验**
- 按页面指引用微信小程序**扫脸核验**（法人本人），当场完成，无需邮寄幕布照。

### 3.3 提交后：管局电话抽查怎么接

云商初审 1-2 天（有问题客服会电话/站内信让你改）→ 提交**北京市通信管理局** → 管局审核 ≤20 个工作日（实际常 3-15 天）。期间可能接到 **管局或云商核查电话**（归属地多为北京 010 固话），务必接听，照下面口径答：

> 问：你网站是做什么的？
> 答：**"我自己写的原创儿童故事，做一个展示故事文字和音频的网站，个人经营的小项目，没有新闻、教育培训这些内容。"**
>
> 问：有没有论坛、评论、用户上传功能？
> 答：**"没有，纯内容展示，用户不能发帖不能上传。"**
>
> 问：服务器在哪买的？网站名称是什么？
> 答：如实回答（腾讯云/阿里云 + 你填的网站名称）。

⚠️ 备案期间该域名**不能开放访问**（服务器上先别绑域名对外服务）。
✅ 通过后收到短信+邮件，含 **ICP 备案号**（北京主体为"**京ICP备2026XXXXXX号**"），记下来，§5 小程序备案要用；网站上线后需在页面底部展示备案号并链接至 `beian.miit.gov.cn`。

## 4. 第4步：注册微信小程序（个体工商户主体）

### 4.1 入口与流程

1. 浏览器打开 `mp.weixin.qq.com` → 右上角"立即注册"→ 选择"**小程序**"。
2. 填【邮箱】（未注册过公众号/小程序的全新邮箱）→ 收激活邮件 → 点击链接激活。

### 4.2 主体信息逐字段

| 字段 | 填什么 |
|:--|:--|
| 主体类型 | `企业` → 细分选 `个体工商户` |
| 企业名称 | 营业执照全称，一字不差 |
| 注册号/统一社会信用代码 | 18 位代码 |
| 主体验证方式 | 推荐选 **法人微信验证**（免费）：填法定代表人姓名+法人本人微信号，24 小时内法人微信收到腾讯推送，点确认即完成。另一方式是对公打款，个体户没开对公户就用法人验证 |
| 管理员信息 | 【姓名】+【身份证号】+【手机号】，管理员扫码绑定本人微信 |

### 4.3 注册完成后立即做

- 头像、名称先随意占位也行，但**小程序名称**建议直接定：`酷酷儿童故事`（若被占用：`酷酷童话屋`、`酷酷讲故事`）。名称同样避开"教育/学习/培训"字样。
- 记录 **AppID**（开发要用，20 号文档的前端工程要填）。

## 5. 第5步：小程序备案

> 与 §3 的 ICP 备案是两件事。2024.3 起小程序不备案不能发布。若 §3 已拿到 ICP 备案号，本步会快很多（主体已在管局有档）。

### 5.1 入口

`mp.weixin.qq.com` 登录小程序后台 → **设置 → 基本设置 → 小程序备案 → 去备案**。

### 5.2 逐字段

| 字段 | 填什么 |
|:--|:--|
| 主体信息 | 自动带出营业执照信息，核对即可 |
| 小程序服务内容类型 | 选 `其他` 或最接近"网络文化内容展示"的非前置审批项；**不选出版、教育、文化（需许可）类** |
| 前置审批 | 全部选 `不涉及` |
| 备案负责人 | 【姓名】+【手机号】+ 人脸核验（微信扫脸） |
| 应急电话 | 家人手机号 |
| 服务说明备注 | 复制 §3.2 的"网站备注"文本，把"网站"改成"小程序" |

### 5.3 时间与电话核查

- 平台初审 1-2 天 → 管局 1-20 个工作日。可能同样有电话核查，话术同 §3.3。
- 备案通过前，小程序可以开发、可以体验版测试，只是**不能正式发布**。

## 6. 第6步：微信认证（¥300/年）

1. 小程序后台 → **设置 → 基本设置 → 微信认证 → 开通**。
2. 逐项：确认主体信息（自动带出）→ 填运营者信息【姓名】【身份证号】【手机号】→ 支付 ¥300 审核费。
3. 之后 1-3 个工作日内，第三方审核公司（如知安、盛大）会**打电话给你**核实：
   > 问：请问是【营业执照全称】吗？申请微信认证是您本人操作吗？小程序做什么用途？
   > 答：**"是的，我本人操作。小程序是我们自己的原创儿童故事内容，给孩子听故事用的。"**
4. 通过后小程序获得认证标识，解锁微信支付申请入口。

## 7. 第7步：微信支付商户号

### 7.1 入口

小程序后台 → **微信支付 → 开通** →"申请接入微信支付"（走小程序内申请，自动关联，最省事）。

### 7.2 逐字段

| 页面步骤 | 字段 | 填什么 |
|:--|:--|:--|
| 主体资料 | 主体类型 | `个体工商户` |
| | 营业执照 | 上传照片/扫描件，填统一社会信用代码、名称（自动识别后核对） |
| | 经营者身份证 | 上传正反面 + 有效期 |
| 经营资料 | 商户简称 | `酷酷儿童故事`（会展示在用户付款页） |
| | 客服电话 | 【手机号】 |
| | 经营场景 | 勾 `小程序`，关联 AppID（自动带出） |
| | **经营类目** | 选 `文娱 → 数字娱乐/数字内容` 相关项（下拉里找"数字内容""在线图文/音频服务"类，**不选教育培训**） |
| 结算账户 | 账户类型 | `经营者个人银行卡`（个体户特权，不需要对公户） |
| | 开户名称 | 【姓名】（必须是经营者本人卡，别人的卡必驳回） |
| | 卡号/开户行 | 按卡填写，开户行支行选准确 |
| 超级管理员 | 姓名/身份证/手机号 | 【姓名】本人信息 + 微信扫码绑定 |

### 7.3 提交后

- 1-2 个工作日出审核结果；通过后微信支付团队向你的结算卡打一笔**随机小额验证款**（几分钱），在申请页回填金额完成账户验证 → 在线签约 → 商户号（mch_id）生效。
- 记录 **商户号** 和自己设置的 **APIv3 密钥**（后端支付对接用，见 11 号文档支付接口）。
- 常见驳回：①身份证照片反光 → 重拍；②结算卡非本人 → 换本人卡；③经营类目与小程序内容不符 → 换成数字内容类目重提。

## 8. 第8步：虚拟支付开通（卖会员必需）

> 会员解锁属"虚拟商品"，2025 年起微信要求虚拟支付走官方"虚拟支付"能力（全终端合规）。个体工商户**可以开通**。

1. 前置确认：✅小程序备案完成（§5）✅微信认证（§6）✅商户号（§7）。
2. 小程序后台左边栏 → **虚拟支付** → 开通页面 → 点【开通】→ 签署协议 → 按指引上传资料（营业执照+经营者身份证，同 §7 材料）。
3. 若页面提示类目不满足：先到 §10 把服务类目补全后再回来开通。
4. 开通后按虚拟支付文档对接（后端对接时再处理，不阻塞资质线）。

## 9. 第9步：软件著作权登记（MVP 能跑后办）

### 9.1 入口（你在北京，可线上可现场）

- **线上**（推荐）：中国版权保护中心 `register.ccopyright.com.cn` → 注册账号（选**企业用户**，用个体户执照）→ 实名认证 → "计算机软件著作权登记申请"，线上填报+上传材料。
- **现场**：中国版权保护中心登记大厅就在北京（西城区天桥南大街 1 号天桥艺术大厦，以官网"联系我们"页公布的地址/取号规则为准），线上填报遇到材料被退、补正看不懂时，可带材料去窗口当面问，比邮件往返快得多——这是在北京的属地优势。

### 9.2 逐字段

| 字段 | 填什么（可复制） |
|:--|:--|
| 软件全称 | `酷酷儿童故事小程序软件` |

| 开发方式 | `独立开发` |
| 开发完成日期 | 代码冻结日 |

| 技术特点 | `前端基于Taro跨端框架开发微信小程序端；后端基于NestJS提供RESTful API；使用PostgreSQL存储内容索引与用户数据；音频内容经由CDN分发播放。` |

### 9.3 材料上传规格

- **说明文档**：用户操作手册（截图 + 文字，10-30 页即可；把 09 号页面清单里的主要页面截图配说明就够）。
- 免费（官费已取消），正常 30-60 个工作日；着急可走加急代办（¥几百-上千，3-35 天）。

## 10. 第10步：服务类目申报（决定是否触发"大证"的关键）

### 10.1 在哪

小程序后台 → **设置 → 基本设置 → 服务类目 → 添加**（最多 5 个）。

### 10.2 申报策略（核心）

| 优先级 | 类目路径 | 所需资质 | 说明 |
|:--|:--|:--|:--|
| **首选** | 按提交时后台实际可选项，选**不要求许可证**的内容/信息类目（如 `商业服务 → 软件/建站/技术开发` 起步占位，或 `文娱 → 资讯` 若开放） | 营业执照即可 | 先让小程序能过审上线 |
| **禁选** | `文娱 → 有声读物/听书/网络小说` | 《网络出版服务许可证》 | 个体/民企办不到，选了必卡 |
| **禁选** | `文娱 → 音乐 / FM电台 / 视频` | 文网文/视听许可证 | 同上 |
| **禁选** | `教育` 全类 | 教育资质 + 双减风险 | 15 号 §1 已定不走教育 |

> 类目列表微信随时调整，申报时逐个点开看"所需资质"栏——**只要资质栏写着"营业执照"以外的许可证，一律不选**。

### 10.3 审核被驳回怎么申诉/回复

提交发布审核后若被驳回"类目不符/缺少资质"，在驳回单的反馈入口或客服通道回复（可复制改写）：

```
您好，本小程序全部故事及儿歌内容均为我方自主原创（AI辅助创作，
著作权归本主体所有），不涉及任何已出版图书、期刊等出版物的有声化
传播，不属于有声读物/网络出版范畴；内容为自有原创数字内容的展示
与播放，恳请按现选类目复审。如内容属性判定确需调整类目，请告知
适用的具体类目，我方将配合调整。
```

- 若微信坚持要求"有声读物"类目+出版许可证：退一步先**去掉付费、纯免费上线**再提审（经营性判定压力骤降）；仍不行则切 §11 的路径 B（SaaS 借资质）。

## 11. 第11步：文网文/出版许可适用性咨询（免费，第 1 周内做）

### 11.1 打给谁（北京）

按顺序打，取交集结论：
1. **010-12345**（北京市政务服务便民热线，说明来意后请对方转**市文旅局**和**市新闻出版局/市委宣传部出版管理部门**，或要对方直线）
2. **北京市文化和旅游局**政务咨询电话（官网 `whlyj.beijing.gov.cn` "政务服务"栏查；文网文在北京由市文旅局审批）——问《网络文化经营许可证》
3. **北京市新闻出版局**（可由 12345 转接）——问《网络出版服务许可证》
4. 一家资质代办商（搜"北京 文网文代办"，只咨询不下单）——代办商对实务口径最敏感，交叉验证官方答复

### 11.2 电话话术（照读）

```
您好，我想咨询一下经营资质适用性的问题。我是北京的一个个体工商户，
做了一个微信小程序，内容是我们自己原创的儿童故事和儿歌，
有文字、图片和音频朗读，没有视频，没有直播，也不是把别人
出版的图书做成有声书，全部内容自己创作、自己配音生成。
小程序里有会员付费，解锁更多自有原创内容。
请问这种情况：
1. 需要办理《网络文化经营许可证》吗？
2. 需要办理《网络出版服务许可证》吗？
3. 如果需要，个体工商户可以申请吗，还是必须公司主体？在北京向哪个
部门提交申请？
```

### 11.3 结论记录与分支

把每通电话的**受话单位、日期、答复**记进 15 号 §2 的评估项，然后：

| 咨询结论 | 行动 |
|:--|:--|
| 都不需要（原创自有内容不涉及） | ✅ 最优，留存记录，按 §10 首选类目上线 |
| 需要文网文，且要公司主体 | 评估：① 先免费上线（非经营性，通常不触发）；② 注册一人有限公司再办证（新增周期 1-3 个月）；③ 付费走 SaaS（小鹅通等，用平台资质收款） |
| 需要出版许可证 | 该证实际办不到 → 确认内容"原创非出版物"口径是否讲清；仍被认定则付费内容走 SaaS 或砍掉"听书"形态表述 |

## 12. 常见驳回/卡点速查表

| 卡点 | 现象 | 解法 |
|:--|:--|:--|
| 北京经营场所不合规 | 住宅地址被驳，提示"非住宅类规划用途" | 按 §1.3 方案②换集中办公区/孵化器托管地址 |
| 个体户名称查重不过 | 字号被占用 | 换字号，2-6 字，试 3-5 个 |
| 域名实名不通过 | 模板信息与执照不一致 | 名称一字不差重传执照 |
| ICP 备案驳回：网站名称 | "名称不符合规范" | 换 §3.2 备选名，避开"网/平台/教育" |
| ICP 备案驳回：内容涉前置审批 | 被认为涉文化/出版 | 服务内容改选"其他"，备注强调"原创自有内容展示、无前置审批项" |
| 管局电话没接到 | 直接驳回 | 重新提交，备案期间陌生固话都接 |
| 微信认证电话核实失败 | 没接到/回答不一致 | 保持手机畅通，回答与执照信息一致 |
| 支付申请驳回：结算卡 | 非本人卡 | 换经营者本人Ⅰ类借记卡 |
| 类目审核要许可证 | 选中了强资质类目 | 按 §10.2 换类目 + §10.3 申诉话术 |
| 小程序名称被占用 | 提示重名 | 依次试：酷酷儿童故事→酷酷童话屋→酷酷讲故事 |
