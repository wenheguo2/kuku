# 17 - 合规资质备案执行指南

> **定位**: 「酷酷儿童故事」上线所需资质/备案的**可照做执行手册**。与 [15-上线合规与资质checklist](15-上线合规与资质checklist.md) 互补——15 号是"要查什么"，本文是"怎么一步步办下来"；每一步的**逐字段填写值与电话话术**见 [21-资质办理操作手册](21-资质办理操作手册.md)。
> **主体口径更新（2026-07）**: 经评估，**个体工商户**即可完成全部必办项（执照/ICP备案/小程序备案/认证/微信支付/虚拟支付/软著），不必注册公司；文网文/网络出版许可证的适用性结论与规避策略见 21 号 §10-§11。
> **前提结论（来自审查 v3 决策）**: 会员+支付进 MVP（需企业主体+微信支付资质）；内容审核走生成管道 AI 机审+抽审（不逐条人工审）；备案不依赖产品做完，**本周即可启动**。
> **重要提醒**: 备案/许可政策与材料清单以**云服务商备案系统、微信公众平台、中国版权保护中心、当地管局**的官方最新要求为准；本文给出流程与时间预期，具体材料按办理时页面提示提交。

## 1. 前置准备（本周 Day 1-2）

### 1.1 主体资质
- **强烈建议用企业主体**（个体户/公司），原因：
  - 付费（会员+微信支付）属经营性，**个人主体无法开通微信支付、无法做经营性 ICP**。
  - 儿童内容 + 付费，平台审核对企业主体更宽松。
- 营业执照经营范围建议包含：**"从事互联网文化活动 / 数字内容服务 / 软件开发 / 信息技术服务"** 等表述（为后续文网文/出版许可留口子）。
- 若已有公司主体：核对经营范围是否覆盖上述，不足则做**经营范围变更**（线上即可，1-3 天）。

### 1.2 域名 + 云服务器
- **云服务器**：选腾讯云 / 阿里云 **中国大陆地域**（备案要求境内服务器），配置按 02 号预算（2 核 4G 起）。备案通常要求**购买时长 ≥ 3 个月**。
- **域名**：在同一云商注册（备案与云商绑定，同商办理最省事）。选 `.com` / `.cn`。
- 买完域名**立即做实名认证**（1-3 天），未实名的域名不能备案。

---

## 2. ICP 备案（工信部）— 本周启动，最长杠杆

> 通过云服务商的备案系统办理，**不用等产品做完**，有服务器+域名+主体信息即可。

### 2.1 办理路径
腾讯云：控制台 → 备案 → 开始备案；阿里云：备案系统 → 备案申请。按向导走。

### 2.2 材料清单（以云商页面为准）
- [ ] 营业执照（企业主体）
- [ ] 法人 / 主体负责人身份证（正反面）
- [ ] 网站负责人身份证 + 手机 + 邮箱
- [ ] 域名证书（云商可一键获取）
- [ ] 服务器信息（云商自动带入）
- [ ] 真实性核验：云商 App 扫脸 / 视频核验（现在多为线上完成，无需寄材料）
- [ ] 网站信息：网站名称、服务内容（填"数字内容/图书阅读听书"，**不填教育培训**）

### 2.3 关键注意
- **经营性 ICP 许可证**：普通 ICP 备案是"非经营性"。若你的付费被判定为"经营性互联网信息服务"，可能需额外办 **ICP 经营许可证（增值电信业务经营许可证）**。⚠️ 实务上：**通过微信内购/虚拟支付卖会员，主体资质走微信支付审核即可，通常不强制个人开发者办经营性 ICP**；先按非经营性备案，付费能力挂在微信支付+小程序内购下。此点在 §6 与法律评估中确认。
- 网站名称**不得含**"教育/培训/学校"等敏感词，也不要用"瞎编"等不专业词（见审查 v3 四.2，已决定改名）。
- 备案期间网站/服务器不能对外提供服务（备案号下来前不开放访问）。

### 2.4 时间预期
云商初审 1-2 天 → 提交管局 → **管局审核法定 ≤20 工作日**（实际常 3-15 天）。**这是全链路最长的外部闸门，所以本周必须启动。**

---

## 3. 微信小程序备案（2024.3 起强制）

> 与 ICP 备案是**两件事**，都要做。小程序备案在微信平台提交，同样不依赖产品完成。

### 3.1 前置
- [ ] 已注册小程序账号（mp.weixin.qq.com，企业主体注册）

### 3.2 办理路径
微信公众平台 → 设置 → 基本设置 → **小程序备案** → 填写并提交。

### 3.3 材料
- [ ] 主体信息（营业执照，与小程序主体一致）
- [ ] 小程序信息（名称、服务内容类目）
- [ ] 备案负责人信息 + 人脸核验

### 3.4 时间预期
微信平台初审 + 管局审核，约 **1-20 工作日**。**须在小程序正式发布上架前完成备案**，否则无法发布。

---

## 4. 微信认证

- 微信公众平台 → 小程序后台 → 微信认证（¥300/年）。
- 认证是**开通微信支付、部分高级接口的前提**，付费进 MVP 则必办。
- 周期 1-3 个工作日。

---

## 5. 微信支付商户号（付费进 MVP 必备）

> R3 决策：会员+支付进 MVP，故此项前置到开发早期。

### 5.1 办理路径
- 方式一：小程序后台 → 微信支付 → 开通（直连商户）。
- 方式二：pay.weixin.qq.com 单独申请商户号后与小程序绑定。

### 5.2 材料
- [ ] 营业执照（企业主体）
- [ ] 法人身份证
- [ ] 对公银行账户（结算用）
- [ ] 已完成微信认证的小程序

### 5.3 关键注意
- **儿童 / 教育相关类目**微信支付审核偏严；按**文娱数字内容 / 图书阅读听书**类目申报（与 15 号 §1 类目一致）。
- 未成年人支付：需在产品侧做**监护人支付确认 + 退款机制**（15 号 §6）。
- 自动续费需明示可取消（合规展示）。
- 周期 1-7 个工作日。

---

## 6. 软件著作权登记（MVP 代码成型后）

> **部分依赖产品**：需要能跑的代码。不用等全部功能，MVP 能运行即可报。

### 6.1 办理路径
中国版权保护中心（register.ccopyright.com.cn）或地方版权局。

### 6.2 材料
- [ ] 源代码：**前 30 页 + 后 30 页**，每页 ≥50 行（不足则全部提交）
- [ ] 软件设计说明书 或 用户操作手册（含截图）
- [ ] 申请表（软件名称、版本号 V1.0、开发完成日期、首次发表日期）
- [ ] 主体证明（营业执照）

### 6.3 时间与加急
- 正常：受理后 **30-60 工作日** 出证。
- 加急：付费可缩短至 **3-35 工作日**（费用随天数递增）。
- **建议**：MVP 代码冻结时立即提交（前后端可各报一件，或合并一件），提前约 1 个月排队，不卡上线。

---

## 7. 文网文 / 网络出版服务许可证 — 适用性评估（先出结论）

> 这是**法律判断题**，不是马上办证，而是先确定"要不要办"。给出结论人和时限。

| 许可 | 可能触发场景 | 初步判断 | 行动 |
|:--|:--|:--|:--|
| 《网络文化经营许可证》（文网文） | 经营性提供音视频、动漫、网络文化产品 | 有声故事/儿歌**可能**涉及 | 咨询当地文旅厅 / 代办，2 周内出结论 |
| 《网络出版服务许可证》 | 提供有声读物、电子出版物 | 儿童故事有声化**可能**涉及 | 咨询当地新闻出版局，2 周内出结论 |
| 《信息网络传播视听节目许可证》 | 提供视听节目 | 纯音频+图文**大概率不涉及** | 若无视频内容，暂列不适用 |

- **执行**：本周内发起咨询（当地政务热线 12345 / 文旅局 / 专业代办各问一遍取交集），2 周内给出"是否需办 + 若需办的周期成本"书面结论，并入 15 号 §2。
- **风险对冲**：营业执照经营范围已含"互联网文化活动"，为后续补证留了口子。

## 8. 内容合规（走 AI 机审，非人工逐条）

> R6 决策：内容审核由**生成管道内置 AI 机审**完成，故事内容生成时已审过，配音质量已加限制处理；不做人工逐条审核。

- [ ] 在 15 号 §3 注明：**审核方式 = 生成管道 AI 机审（已内置）+ 上线前抽审**，不逐条人工审（对齐 05 B-10 与 15 号，消除表面矛盾）。
- [ ] 保留生成时的 AI 审核日志/规则作为合规留痕。
- [ ] 上线前对配音质量做一次**抽审**（重点抽近期/低置信度批次）。
- [ ] 建立内容举报与下架通道（15 号 §3）。
- [ ] AI 生成内容标注，符合《生成式 AI 服务管理办法》。

## 10. 执行时间线（并行推进）

```
本周 (Day 1-7)
├─ Day 1-2  确认企业主体 + 经营范围；买域名+服务器；域名实名
├─ Day 2-3  发起 ICP 备案（云商系统，扫脸核验）        ← 最长杠杆，最先启动
├─ Day 2-3  注册小程序 → 提交小程序备案 → 微信认证
├─ Day 3-5  申请微信支付商户号（认证通过后）
└─ Day 1-5  发起文网文/网络出版适用性咨询（2 周内出结论）

第 2-4 周（并行等审核）
├─ 管局审核 ICP / 小程序备案（≤20 工作日）
└─ 产品开发推进（不阻塞）

MVP 代码冻结时
└─ 提交软件著作权登记（可加急，提前约 1 个月）

上线前
└─ 隐私政策上线 + 内容抽审 + 15 号全部 P0 达标 → 提交小程序审核发布
```
