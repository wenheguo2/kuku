# 09 - 页面清单与信息架构

> **目标读者**：UI 设计 / 前端 / 产品
> **文档作用**：在 UI 设计开工前，锁定"到底有哪些页面、每页职责、页面间跳转关系、所属阶段"，作为设计与前端开发的**页面边界基准**。
> **权威口径**：页面 ID（本文定义的 `S/M/G/PL/C/A/U/ADM` 命名空间）为跨文档引用页面时的单一数据源；功能细节以 PRD（ST-/SG-/ED-/PR- 编号）为准，决策以 [05-决策点清单](05-决策点清单.md) 为准，索引结构类型以 [10-索引与封面设计方案](10-索引与封面设计方案.md) 为准。

## 四、缺口清单（概念图未覆盖，需补设计）

按优先级排序，**前两项是 MVP 必须但概念图漏画的关键页**：

1. 🔴 **A-01 登录/微信授权页** — PRD 标 P0，概念图完全没画，MVP 阻塞项。
2. 🔴 **C-06 独立设置页** — 承载刚确认的主题切换（深/浅/跟随系统，PR-004a），目前只嵌在家长中心，需独立页。
3. 🟠 **S-05 混合型页 / S-06 多层分类页** — 故事结构 4 类型里的 2 类无概念图，故事 Tab 无法完整浏览。
4. 🟠 **G-05 综合挑战页 / G-06 挑战结果页** — 成长闭环（收听→挑战→结果）缺后半段。
5. 🟡 **C-05 搜索输入/联想页** — 仅有结果态。
6. 🟡 **PL-04 笔画动画** — 需先定"是静态图/动画/第三方"再谈设计。
7. 🟡 **U-01~U-05 通用状态页** — 启动/引导/空/加载/错误，须成套。
8. 🟡 **A-03/A-04 会员+支付** — 已进 MVP（决策 R3），需补设计稿；A-02 档案页仍可后置到 P1。

## 五、MVP 页面范围建议

MVP（Phase 1）建议纳入以下页面完成设计与开发：

- **全局**：GL-01、GL-02
- **故事**：S-01 ~ S-06（含补画的 S-05/S-06）
- **歌曲**：M-01 ~ M-03
- **成长**：G-01 ~ G-06（含补画的 G-05/G-06）
- **播放器**：PL-01 ~ PL-03（PL-04 视笔画方案定）
- **通用**：C-03、C-04、C-05、C-06（设置含主题切换）
- **账户**：A-01（P0 登录）、A-03（会员权益）、A-04（支付）、A-05（账号注销/数据删除，合规）
- **状态页**：U-01、U-03、U-04、U-05

**后置到 P1/P2**：C-01/C-02（家长中心+进度）、A-02（档案独立页）、U-02（引导）、ADM-*（后台）。

> 注：家长中心 C-01/C-02 在 PRD 中为 P1，但"设置/定时/主题切换"等高频项已拆到 C-06 独立设置页纳入 MVP，避免 MVP 无处切主题。
