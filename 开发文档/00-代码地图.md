## 一、总体结构

```
项目/酷酷儿童故事/
├── server/      # NestJS 后端（API + 静态资源服务，本地替代 CDN）✅ 已跑通验证
├── miniapp/     # Taro 3 + React 小程序（故事/歌曲/成长/家长）✅ type-check 通过
├── admin/       # Vue 3 + Element Plus 管理后台（P1，脚手架）
├── production/  # 内容资产（索引/音频/图片，脚本产出）
├── 脚本/        # 内容生产管线（01~10）+ 11_validate_index.py(索引校验) + 12_generate_home_index.py(首页推荐)
├── md/          # 产品与架构设计文档（00~20）
└── 开发文档/    # 代码级实现文档（本目录）
```

三端共同契约：**统一响应包络 `{code,message,data}`**（md/11）；**索引/媒体走静态资源不经 /api/v1**；**朋友等级 current_stage 0/1/2/3**。

## 二、server/（NestJS 后端）

详见 [server/README.md](server/README.md)。

```
server/src/
├── main.ts                 # bootstrap：全局前缀 /api/v1 + 响应拦截器 + 异常过滤器 + ValidationPipe + 安全响应头
├── app.module.ts           # 根模块：Config/环境门禁 + TypeORM + ServeStatic(/static) + 全局 JWT/VIP 守卫 + 12 业务模块
├── db/schema.sql           # ★ 12 表建表基线（含 consent_records，= md/08 §2.2）
├── entities/               # 12 个 TypeORM 实体（synchronize=false，仅映射）
├── common/                 # 响应拦截器 / 异常过滤器 / JWT 守卫 / @Public / @CurrentUser / 分页
├── config/                 # database.config（TypeORM 工厂）
└── modules/
    ├── health/             # GET /health（探活 + DB 探测）
    ├── auth/               # 微信登录(mock/real) + 监护人同意留痕 + JWT + ★自动建默认档案 + 账号注销
    ├── favorites/          # 收藏（账号共享）
    ├── history/            # 播放历史（★按 child_id 隔离，UPSERT）
    ├── track/              # 埋点
    ├── progress/           # ★四级朋友：学习/普通挑战(服务端判分·无惩罚可无限重试)/综合挑战(逐字·只升不降)/总览/字词面板(按亲密度筛选)
    ├── parent/             # 家长设置 + 本周成长 + 明细
    ├── children/           # 孩子档案 CRUD + 所有 child_id 入口统一归属校验
    ├── achievements/       # ★成就贴纸 + 朋友收集册聚合（会员门控 @Vip）
    ├── membership-access/  # @Global 会员校验服务（VIP 门控共用）
    └── billing/            # 会员状态 + 订单（微信支付 stub → 开通会员）
    └── admin/              # ★ 管理鉴权(scrypt/JWT 登录) + 数据库聚合统计
```

**运行**（PG/Memurai 已装并 Running）：
```bash
cd server
npm install
npm run db:init        # 建 12 表（或用 psql 执行 src/db/schema.sql）
npm run start:dev      # http://localhost:3000/api/v1
```
> ⚠️ 需先建库：`CREATE DATABASE kuku_stories;` + 应用账号 `kuku_app`（见 md/08 §2.1）。`.env` 见 `.env.example`。

**已验证**：health(db:true) / 静态 _global.json / 登录建默认档案 / 学习 0→1 / 挑战服务端判分+重试 / 收藏 / 下单→会员开通 / 401 守卫。

## 三、miniapp/（Taro 小程序）

详见 [miniapp/README.md](miniapp/README.md)。

```
miniapp/src/
├── app.config.ts           # 4-Tab(★custom SVG TabBar) + 24 页面注册 + requiredBackgroundModes:['audio']
├── app.tsx / app.scss      # 入口(恢复登录态+主题) / 全局样式 + v4 组件库(hero/tile/故事灯/夜/鎏金/徽章墙…)
├── custom-tab-bar/          # ★ v4 自定义 SVG 底栏(书/音符/嫩芽/家庭)，夜间联动
├── styles/variables.scss   # 设计令牌(= design-tokens v4) + 日/夜/鎏金/衬线 CSS 变量
├── components/             # Icon(SVG→dataURI,28图标) / MiniPlayer(GL-02玻璃) / StateView(空/错/载)
├── hooks/                  # useNight(全局睡前夜间：定时/手动，根节点 .theme-dark + TabBar 换色)
├── services/               # config / api / indexLoader(loadGlobal/Home/ByPath/Segments) / audioPlayer / storage / mock
├── utils/                  # path(buildAssetUrl/buildCoverUrl/buildIndexUrl) / lrc / timeline
├── stores/                 # userStore / settingsStore(主题+睡前 isNight) / playerStore(续播队列) / tabStore(当前Tab)
└── pages/
    ├── story/  index(S-01首页) subject(S-02学科) list(S-03/05/06) work(S-04章回) player(PL-01故事灯)
    ├── song/   index(M-01音乐厅) player(PL-02歌词 light) list(M-02/M-03分类下钻)
    ├── growth/ index(G-01收集册) lesson(G-02/03) player(PL-03横屏) challenge(G-04) comprehensive(G-05/06) collection(收集册可视化)
    ├── parent/ index(C-01磨砂卡)
    └── common/ login(A-01) favorites(C-03) history(C-04) settings(C-06睡前模式) member(A-03鎏金) search(C-05) children(A-02) agreement(协议阅读) account-delete(A-05注销)
```

**运行**：
```bash
cd miniapp
npm install
npm run dev:weapp      # 微信开发者工具导入 dist/（详情→本地设置→不校验合法域名）
```
> `services/config.ts` 的 `USE_MOCK=true` 可脱离后端跑 UI；接后端改 `false`。
